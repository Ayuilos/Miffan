Patch-release scope: user-visible fixes only. Direct cherry-picks retain `-x`; hand ports keep the upstream subject and an `(adapted from upstream …)` line.

Applied:

- `395a0ee03` → `b117bd65a`: favorite-model drag reordering no longer jitters. Direct cherry-pick.
- `9dcb4fa44` → `857ed1122`: model matching no longer reads parameter counts (8b, a3b, 32k) as versions, so e.g. qwen3-8b is not marked image-capable. Direct cherry-pick with its tests.
- `4af510624` → `ff35fb94f`: two back presses in one frame no longer empty the navigation stack and crash. Same one-line guard in Miffan's `RouteActivity`.
- `17d06d26f` → `bd503ec85`: after adding or importing a provider, the list clears the search and scrolls to it once it is saved. Miffan's provider page has no recommended-provider button and does not open the detail page after adding, so only the shared `addProvider` path was ported.
- `281c9525a` → `5d3862501`: a message sent right after stopping no longer stays stuck in a paused queue. In Miffan the pause lives in `ConversationSession.setJob`; every cancellation goes through `stopGeneration` (which pauses first), a guarded replacement, or cleanup, so a cancelled turn no longer pauses on completion. Two tests that cancelled jobs directly now stop through `stopGeneration`; a new regression covers sending between stop and the turn's end (fails without the fix).
- `eb530b0ff` → `ddfff8686`: `<` inside formulas no longer breaks the HTML renderer, and `\\[4pt]` line breaks are neither taken as `\[` delimiters nor drawn as text. Ported to `MarkdownNew.kt` (escaping math provider; same markdown library version as upstream), the delimiter regexes of both `Markdown.kt` and `MarkdownNew.kt`, and `LatexText.kt`. New `MarkdownMathTest`.
- `bdb2ddc73` → `459e77d0e`: an empty `b64_json` (or url) in an OpenAI-style image response counts as missing, so relays that send both no longer produce a 0-byte image. Ported to the ai module's `base64ImageOrNull` and `parseImageResponse`; the compatibility test now sends an empty `b64_json` beside a url. Download logging not ported.
- `96a9bed4d` → `2e76856b2`: the image preview's "saving" toast is dismissed when saving finishes instead of stacking with the result. Uses Sonner's `dismiss`; upstream's new progress-toast API and strings were not ported.

Not applicable:

- `9b458a67c` (long bubbles lose touches past 8192 px): only bubbles with uneven corner radii use a Path outline; Miffan's message bubbles use uniform corners, and its one uneven shape (the quiz card) never gets that tall.
- `42896e5ad` (MCP list crash on Compose UI 1.12): Miffan's MCP picker is a Card/Row, not a `ListItem` with a multi-child supporting slot.
- `222bc4ad1` (MiniMax video result auth): the app never downloads video-generation outputs.
- `2aafd708f` (skill deletion): Miffan's skills live in workspaces with a different manager and no upstream skills pages.
- `183a7da70` (sketch), `2b4694ba7` (floating window), `6fa164050`, `e48db7bc7` (file-based memory): the features do not exist in Miffan.

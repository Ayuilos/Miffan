- `281c9525a` → `5d3862501`: a message sent right after stopping no longer stays stuck in a paused queue. - `eb530b0ff` → `ddfff8686`: `<` inside formulas no longer breaks the HTML renderer, and `\\[4pt]` line breaks are neither taken as `\[` delimiters nor drawn as text. Ported to `MarkdownNew.kt` (escaping math provider; same markdown library version as upstream), the delimiter regexes of both `Markdown.kt` and `MarkdownNew.kt`, and `LatexText.kt`. New `MarkdownMathTest`.
- `bdb2ddc73` → `459e77d0e`: an empty `b64_json` (or url) in an OpenAI-style image response counts as missing, so relays that send both no longer produce a 0-byte image. Ported to the ai module's `base64ImageOrNull` and `parseImageResponse`; the compatibility test now sends an empty `b64_json` beside a url. Download logging not ported.
- `96a9bed4d` → `2e76856b2`: the image preview's "saving" toast is dismissed when saving finishes instead of stacking with the result. Uses Sonner's `dismiss`; upstream's new progress-toast API and strings were not ported.

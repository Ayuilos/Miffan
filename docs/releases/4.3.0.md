### Miffan 自有改动

- 伙伴可以帮你画图、改图了：在「我 → AI 服务 → 画图」（专业模式在「默认模型」）选一个画图模型，所有助手和伙伴都能按需画图。支持 ChatGPT 订阅、OpenRouter 和其他能出图的服务；画好后接着说「把它改成……」，伙伴会在上一张图上修改，也可以用网上的图片做参考。
- 画图还没开启时，伙伴会在聊天里请你开启，选好模型后这次画图直接继续；轻松聊天模式下画好的图直接显示在回复里。
- 选择画图模型时按「订阅内，不额外花钱」「按用量付费」「你添加的」分组，并推荐一个合适的模型；价格按图像输出标注，不会把按张收费的模型误标为免费。
- 连接电脑重新设计：轻松聊天模式先在同一 Wi-Fi 里寻找电脑，Tailscale 上的电脑单独列出，也可以直接输入地址，支持粘贴 user@host:port 或 ssh 命令。
- 登录电脑只需账号和密码，Miffan 会自动改用自己的密钥；只接受密钥的电脑会给出一条命令完成设置，以前添加过的电脑不用再输密码。
- 已保存的电脑排在最前面，并记住多个地址，换网络时会自动尝试；双系统电脑的两个系统能分开识别，不会用错账号。
- 删除电脑时可以顺带从电脑上移除 Miffan 的密钥和辅助程序，并解除高画质模式的配对；电脑连不上时也可以只从手机上删除。
- 修复高画质模式重新配对时，电脑已显示配对成功、手机却提示失败的问题。
- 修复已保存的电脑改了密码后停在报错页的问题，现在会重新打开登录；修复删除 Windows 电脑时命令执行失败的问题。
- 助手详情页可以清除单独选择的模型，恢复使用全局默认模型。

Updates:

### Miffan changes

- Partners can now draw and edit pictures: choose an image model under Me → AI service → Drawing (Default model in professional mode) and every assistant and partner can draw when asked. ChatGPT subscriptions, OpenRouter and other image-capable services work; after a picture is made, say "change it to…" and the partner edits that picture, or give it an image from the web as a reference.
- When drawing is not turned on yet, the partner asks you in the chat, and once you pick a model that same drawing carries on; in easy mode the finished picture appears right in the reply.
- The image model picker groups models into "Included in your subscription", "Pay as you go" and "Added by you" and recommends one; prices follow the image output cost, so per-image models are no longer shown as free.
- Connecting a computer is redesigned: easy mode first looks for computers on this Wi-Fi, lists Tailscale computers separately, and still lets you type an address, including a pasted user@host:port or ssh command line.
- Signing in to a computer needs only the account and password, after which Miffan switches to its own key; a computer that only takes keys gets a one-command setup, and computers added before connect without a password.
- Saved computers come first and remember several addresses, which are tried when you change networks; the two systems of a dual-boot computer are told apart, so the wrong account is never used.
- Deleting a computer can also remove Miffan's key and helper from it and unpair high-quality mode; when the computer cannot be reached, you can delete it from the phone only.
- Fixed high-quality mode re-pairing failing on the phone although the computer showed it as paired.
- Fixed a saved computer with a changed password stopping at an error; it now opens the sign-in again. Fixed commands failing while deleting a Windows computer.
- The assistant detail page can clear its own model choice and go back to the global default model.

### Miffan 自有改动

- 修复伙伴在 Linux（Wayland）电脑上输入中文时，每次卡住 20 秒后失败的问题。
- Mac 在锁屏状态下打开远程屏幕时，即使开着高性能模式，也会先用普通连接，方便输入密码解锁；解锁后可从菜单切到高性能模式。
- 修复在 Mac 上用普通连接解锁后切到高性能模式，Mac 立即重新锁屏、且无法再输入密码的问题。
- Mac 高性能模式下，左右切换桌面、调度中心、显示应用窗口这几个快捷按钮恢复可用（需要 Mac 上装有 cua-driver）。

Updates:

### Miffan changes

- Fixed partners typing Chinese on a Linux (Wayland) computer: each attempt hung for 20 seconds and then failed.
- Opening the remote screen of a locked Mac now uses the normal connection even when high-performance mode is on, so you can type the password to unlock it; afterwards, switch to high-performance mode from the menu.
- Fixed a Mac locking again right after switching from the normal connection to high-performance mode, with no way to type the password.
- In high-performance mode on a Mac, the buttons for switching desktops left and right, Mission Control and app windows work again (requires cua-driver on the Mac).

### Synced from RikkaHub

- No user-facing changes in this release.

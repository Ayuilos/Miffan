### Miffan 自有改动

- 首次打开改成和 Miffan 聊天：连上 AI 服务（OpenRouter 一键登录或粘贴 API Key），自己挑一个聊天模型，再选第一个伙伴，它会主动跟你打招呼。每一步都能退回重选，也可以直接从备份恢复。
- 连接失败时会说清原因：Key 不对、连不上、服务出错，或者这个服务没有能聊天的模型。聊天中余额不足时，会提示你去「服务连接」查看。
- 新伙伴打招呼后，下面会附几个现成的回答，点一下就发出；你自己打字回复后，这些选项会收起来。审批、提问等聊天卡片也统一了样式。
- 伙伴资料页新增「想多久再回」，可选秒回、看情况、多想想和深思熟虑；遇到难题时，可以在输入框的 + 菜单里选「这次认真想想」，只对下一条消息生效。想得久时，顶部会显示已经想了几秒。
- 伙伴需要日历、剪贴板、使用时长等能力时，会在聊天里请你打开，同意后它接着把事做完。资料页也新增了这些能力的开关，「提问」默认打开。
- 伙伴的问题被你直接在聊天里回复跳过后，不会消失，而是收成一行，点开还能看到问了什么。
- 「检查电脑状态」改为打开新的电脑状态页：一句话说明电脑现在怎么样，发现问题就地修好；电脑页不用连接也能看到上次检查的结果。
- 操作小助手有新版本时，状态页会提示更新。更新会等伙伴手上的事做完再开始，期间伙伴不会操作这台电脑，你不在页面上时完成后会通知你。
- 更新操作小助手更稳妥：网络太慢时不会动现有版本；Windows 改为跟随官方稳定版，新版本出问题会自动退回原来的版本，并修复了 Windows 上安装可能被意外中断、下载失败却显示成功的问题。

### Miffan changes

- First launch is now a chat with Miffan: connect an AI service (one-tap OpenRouter sign-in or a pasted API key), pick a chat model yourself, then choose your first partner, who says hello on its own. Every step can be taken back, and you can restore from a backup instead.
- When connecting fails, Miffan says why: a wrong key, no connection, a service error, or no chat model on that service. If a chat hits a balance error, it points you to Service connection.
- A new partner's hello comes with a few ready replies you can send with one tap; they fold away once you type your own. Approval, question and other cards in chats now share one look.
- New "How long to think" on a partner's page: Instant, Depends, Think more or Think deeply. For one hard question, pick "Think hard this time" in the + menu; it applies to the next message only. While a partner thinks for long, the header counts the seconds.
- When a partner needs your calendar, clipboard, screen time or another ability, it asks in the chat and carries on once you allow it. The partner's page also has switches for these abilities, and asking you questions is on by default.
- A partner's question that you skipped by replying in the chat no longer disappears; it folds into one line you can open to see what was asked.
- "Check computer status" now opens a computer status page: one line says how the computer is doing, problems are fixed in place, and the computer's page shows the last result without connecting.
- When the control helper has a new version, the status page offers the update. It waits for the partner to finish what it is doing, keeps partners off that computer while it runs, and notifies you when it is done if you are not watching.
- Updating the control helper is safer: nothing changes on a network too slow to download it; Windows follows the official stable release and goes back to the previous version if the new one fails; and an install on Windows no longer stops on a harmless message or reports a failed download as success.

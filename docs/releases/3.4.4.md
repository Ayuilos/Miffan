更新内容：

### Miffan 自有改动

- Agent 可将需要交互的远程命令交给终端执行；你按回车并输入密码后，执行结果会返回聊天，Agent 自动继续响应。
- 同一对话复用远程终端会话，保留工作目录与环境变量；手动执行 `sudo -v` 后，Agent 可在服务器授权有效期内使用 `sudo -n`。
- 输入框上方显示终端会话状态，可快速定位相关命令或结束会话，长对话中也能随时操作。
- 修复在部分弹窗中切换主题时可能发生的崩溃。

### 同步自 RikkaHub

- 修复 Responses API 将可选工具参数强制填充的问题。
- 复制过大的请求日志时显示失败提示，避免应用崩溃。
- 修复 JSON 详情弹窗中长按选中文本时可能发生的崩溃。

Updates:

### Miffan changes

- Agents can hand interactive remote commands to the terminal. Press Enter and enter your password there; results return to chat and the agent continues automatically.
- Reuse the remote terminal session within a conversation, preserving its working directory and environment. After manually running `sudo -v`, the agent can use `sudo -n` while the server's authorization remains valid.
- Show terminal session status above the input, with shortcuts to locate the command or end the session even in a long conversation.
- Fix a possible theme crash in some dialogs.

### Synced from RikkaHub

- Keep optional Responses API tool arguments optional instead of forcing placeholder values.
- Show a failure message when a request log is too large to copy, preventing an app crash.
- Fix a possible crash when selecting text in the JSON detail sheet.

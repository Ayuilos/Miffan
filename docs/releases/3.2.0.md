Updates:

### Miffan changes

- Conversations now use a persistent message tree, preserving branches across restarts while safely migrating existing chats.
- Editing a message now preserves its reply branch. A message-path overview was added, and search results can navigate to the correct branch.
- The new-conversation page now shows recent chats for quicker access.

### Synced from RikkaHub

- Improved TTS stability and retry handling. Default playback speed was moved to general preferences, with completed localization.
- Added a setting to disable automatic retries for model requests after network errors.
- Fixed Gemini request and streaming-result handling when built-in and client-side tools are used together.
- Improved MCP client compatibility and fixed OAuth authorization detection for Cloudflare MCP servers.
- Switched image selection to the system photo picker for better compatibility and privacy.
- Added configurable reasoning levels for the fast model and disabled inline HTML/SVG previews by default.
- Refined UI details by rounding bubble-opacity percentages, hiding memory IDs, and removing the unavailable SiliconFlow balance query.

更新内容：

### Miffan 自有改动

- 在外经中转看电脑屏幕，改为显示截图：每隔几秒刷新一次，点按或输入后马上刷新，比实时画面省流量，点完也能更快看到结果。需要电脑上装有 cua-driver。Mac 和 Linux 可以在屏幕页的菜单里点「改用实时画面」切回去。
- Windows 电脑在外也能看屏幕了，同样以截图方式显示。
- 修复连接 Windows 电脑时提示「Could not install the Miffan helper」、一直连不上的问题。

### 同步自 RikkaHub

- 本次无面向用户的改动。

Updates:

### Miffan changes

- Viewing a computer's screen through the relay now shows snapshots: refreshed every few seconds and right after you tap or type. They use less data than the live picture, and you see the result of a tap sooner. The computer needs cua-driver. On a Mac or Linux computer, Use the live picture in the screen page's menu switches back.
- A Windows computer's screen can now be viewed away from home too, as snapshots.
- Fixed connecting to a Windows computer failing with "Could not install the Miffan helper".

### Synced from RikkaHub

- No user-facing changes in this release.

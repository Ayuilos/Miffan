### Miffan 自有改动

- Claude Fable 5.2 做的一轮性能优化：这一版的改动全部来自 Claude 最新模型 Fable 5.2，它逐个函数测量了「伙伴正在回复」时手机在忙什么，再把最费时的部分重写了一遍。下面是结果。
- 伙伴回复时更流畅：回复一边出字，画面一边滚动也不再掉帧，回复很长或出字很快时最明显；在 OPPO Find X6 Pro 上实测，掉帧从 9%–18% 降到约 1%。同时打字、开始滑动也更跟手。
- 输出代码不再越写越卡：伙伴写长代码时，只处理新写出的几行，不再每次把整段代码重新上色和排版。
- 长代码也有颜色：超过约四千字的代码块以前是单色，现在同样有语法高亮。
- 回翻长聊天更顺：往回翻有很多长回复的聊天时，掉帧更少。
- 回复时更省电：同样一条回复，手机要做的计算少了大约一半。
- 日志更干净：正式版不再把对话内容写进系统日志，几家服务的密钥也不会再出现在日志里。
- 轻松模式里的一处小变化：从「全部设置」打开助手页时，头像直接出现，不再飞入；专业模式不变。

### Miffan changes

- A performance pass by Claude Fable 5.2: every change in this version comes from Claude's newest model, Fable 5.2, which measured function by function what the phone is busy with while a partner replies and reworked the costliest parts. The results follow.
- Smoother while a partner replies: the page keeps up with the text without dropping frames, most of all with long or fast replies; measured on an OPPO Find X6 Pro, dropped frames went from 9–18% to about 1%. Typing and starting a scroll respond sooner too.
- Code no longer slows down as it is written: while a partner writes long code, only the new lines are worked on instead of coloring and laying out the whole block again each time.
- Long code has colors too: code blocks over about four thousand characters used to be one color and are now highlighted like the rest.
- Smoother scrolling back through long chats: fewer dropped frames in chats with many long replies.
- Easier on the battery while replying: the phone does about half the work for the same reply.
- Cleaner logs: release builds no longer write conversations to the system log, and the keys of a few services no longer appear there.
- One small change in the easy interface: opening an assistant page from "All settings" shows its avatar in place instead of flying it in; the professional interface is unchanged.

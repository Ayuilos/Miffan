### Miffan 自有改动

- 远程电脑可以跑定时任务了：在聊天里请伙伴安排，任务由电脑自己的定时器按时运行（Linux 和 Mac），手机关机也不影响。Windows 电脑暂不支持，App 里会说明。
- 定时任务可以是一条命令，也可以调用电脑上已装好的 AI 工具。内置 Claude Code、Codex CLI、Gemini CLI，也可以添加自己的工具；费用记在电脑上这个工具自己的账号上。
- 安排或修改定时任务都要你在卡片上批准。卡片写清名称、时间和要做的事，修改时标出原来的值，还可以选择批准后要不要马上试跑一次。
- Agent 工具也可以交给伙伴来配置：添加、修改、删除都要你批准，修改时显示改前改后的对比，并可以顺便更新用到它的任务。
- 定时任务的结果在你打开 Miffan 时同步回来：每个任务在聊天里留一行记录，设成要汇报的任务由伙伴说明结果，聊天顶部会提示你不在时电脑跑了几次任务。
- 「我的电脑」里可以看到每台电脑的定时任务、最近运行结果和每次的输出；伙伴资料页会列出它安排的任务，电脑相关的设置也集中到了一起。
- 删除电脑并让它忘掉 Miffan 时，不再顺带删掉伙伴留在电脑上的文件；可以自己选择要不要一起删，并能看到这些文件占了多少空间。
- 删除电脑并让它忘掉 Miffan 时，只删除这部手机安排的定时任务，其他手机安排的任务会继续运行。

### Miffan changes

- Remote computers can now run scheduled tasks: ask a partner in chat, and the computer's own scheduler runs the task on time (Linux and Mac), even while your phone is off. Windows computers are not supported yet, and the app says so.
- A scheduled task can be a command or a call to an AI tool already installed on the computer. Claude Code, Codex CLI and Gemini CLI are built in, and you can add your own tools; usage is billed to that tool's own account on the computer.
- Every new or changed scheduled task needs your approval on a card that shows its name, time and what it does. Changes show the previous values, and you can choose whether to run it once right after approving.
- Partners can also set up Agent tools for you: every add, change or removal needs your approval, changes show a before-and-after comparison, and the tasks that use the tool can be updated at the same time.
- Results of scheduled tasks arrive when you open Miffan: each task leaves one line in the chat, the partner explains results for tasks set to report, and a banner at the top tells you how many runs happened while you were away.
- "My computers" shows each computer's scheduled tasks, their latest results and the output of every run; a partner's profile lists the tasks it set up and now groups the computer settings together.
- Deleting a computer and having it forget Miffan no longer also deletes the files partners left on it; you can choose to delete them too and see how much space they take.
- Deleting a computer and having it forget Miffan removes only the scheduled tasks set up from this phone; tasks set up from other phones keep running.

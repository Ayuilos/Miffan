更新内容：

### Miffan 自有改动

- 简单模式的「AI 服务」整合为一个页面：在这里查看已连接的服务、选择默认模型和后台整理模型。「我」页面不再单独列出后台整理，后台整理出问题时「AI 服务」会显示「需要检查」。
- 远程电脑支持没有屏幕的服务器和 NAS：
  - 添加电脑时可以关闭「使用屏幕」，跳过桌面和屏幕相关的检查，伙伴通过命令使用这台电脑；
  - 「询问 / 自动 / 关闭」的操作模式同样适用于没有屏幕的电脑，不用每条命令都点一次批准。
- 远程屏幕的按键栏里，回车键固定在最右侧，不用来回滑动寻找。
- 设置里的「使用文档」改为打开 Miffan 使用指南，和「关于」页面一致。

### 同步自 RikkaHub

- 本次无面向用户的改动。

Updates:

### Miffan changes

- Easy mode's "AI service" is now one page: see your connected services and pick the default model and the background helper's model there. The Me tab no longer lists the background helper on its own; when the helper has a problem, "AI service" shows "Needs attention".
- Remote computers now work without a screen, such as servers and NAS boxes:
  - When adding a computer you can turn off "Use the screen" to skip the desktop and screen checks; partners then use the computer through commands.
  - The Ask / Automatic / Off mode also applies to computers without a screen, so commands no longer need a tap each time.
- On the remote screen key bar, Enter stays pinned on the right, so you don't have to scroll for it.
- "Documentation" in Settings now opens the Miffan guide, the same as the About page.

### Synced from RikkaHub

- No user-facing changes in this release.

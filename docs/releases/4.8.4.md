### Miffan 自有改动

- 只看一个窗口：屏幕页可以挑一个窗口单独显示，还能把窗口调成适合手机的大小，你一操作它就会被切到最前面。支持 Linux 的 GNOME、KDE Plasma、niri 和 X11 桌面（GNOME 第一次使用要装一个小扩展并重新登录）；Mac 为实验功能，需要电脑上装好 cua 的桌面服务，被挡住或在别的桌面上的窗口也能看。
- 按键栏重新设计：按键行只放 Esc、Tab、按住会连发的方向键和回车；修饰键、常用快捷键（Mac 上用 Command）、Home/End/翻页/Del 和 F1–F12 收进快捷键面板，和输入法像聊天软件的表情面板一样来回切换。横屏打开键盘时只盖住画面下半部分，不再把桌面挤成小图。
- 记住指针模式：直接点按还是触控板模式，下次打开屏幕时保持你上次的选择。
- 状态一眼看懂：电脑名字下面那行改成图标，圆点表示连接状态，胶囊表示画面模式和清晰度，云朵表示经中转连接；读屏软件仍会读出完整状态，流量用量移到了连接详情里。
- 小电脑画面保持最新：看完小电脑的屏幕回到它的页面，显示的是刚才的最新画面，不再是旧截图。
- 更新页面跟随角色：更新页、「我」页的更新卡片和「新变化」卡片会显示当前的角色形象，用鲸鱼主题时就是鲸鱼。
- Linux 换桌面后更可靠：在同一台电脑上注销后换成另一种桌面（比如从 niri 换到 KDE），屏幕也能正常打开；电脑上没人登录时会如实提示，不再让你去装 x11vnc。
- GNOME 不再误报远程桌面：GNOME 远程桌面用的证书文件丢失后，Miffan 会重新配置，不再误报「这台电脑在 Miffan 之外已经开启了远程桌面」。

### Miffan changes

- Show just one window: the screen page can show a single window you pick and resize it to fit your phone, bringing it to the front as soon as you act on it. Works on Linux with GNOME, KDE Plasma, niri and X11 desktops (GNOME needs a small extension and a new login the first time); on a Mac it is experimental, needs cua's desktop service on the computer, and can show windows that are covered or on another desktop.
- Redesigned key bar: the key row keeps only Esc, Tab, arrows that repeat while held, and Enter; modifier keys, common shortcuts (Command on a Mac), Home/End/Page Up/Page Down/Del and F1–F12 move into a shortcuts panel that swaps places with the keyboard, like a chat app's emoji panel. In landscape the keyboard covers only the lower part of the picture instead of shrinking the desktop to a thumbnail.
- Pointer mode remembered: direct touch or touchpad, the screen opens in the mode you used last time.
- Status at a glance: the line under the computer's name is now icons, a dot for the connection, a pill for the picture mode and quality, and a cloud for a relayed connection; screen readers still read the full status, and data used moved to the connection details.
- Mini box pictures stay current: after you view a mini box's screen, its page shows the latest picture instead of an old screenshot.
- Update screens follow your character: the update page, the update card on Me and the what's-new card show your current character, the whale when the whale theme is on.
- Steadier after switching Linux desktops: logging out and into another desktop on the same computer (say from niri to KDE) no longer stops the screen from opening, and when nobody is logged in at the computer Miffan says so instead of asking you to install x11vnc.
- No false remote desktop warning on GNOME: if the certificate files GNOME's remote desktop uses are gone, Miffan sets it up again instead of saying remote desktop was turned on outside Miffan.

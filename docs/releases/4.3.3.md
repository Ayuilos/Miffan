更新内容：

### Miffan 自有改动

- 终端可以正常显示和输入中文：连接远程电脑时会自动使用 UTF-8 编码，中文文件名和输出不再变成乱码；输入时不再弹出只能打英文的系统安全键盘，可以用自己的输入法，远程终端打拼音时还会在光标处显示正在输入的内容。
- 终端换了更舒服的样式：统一使用等宽字体，改用柔和的深色配色，文字也不再贴着屏幕边缘。
- 高性能模式新增「自定义」画质，可以在 720p 到 4K、30 到 120 帧之间自由组合（比如 1080p 30 帧）；超过电脑屏幕的尺寸会自动降到合适大小。
- 专业模式编辑电脑时可以管理它的所有地址（所在网络、上次使用、删除、添加），修改后立即生效，也不会再丢掉已信任的电脑身份；电脑卡片会显示优先尝试的地址和其余地址的数量。
- 系统语言为繁体中文时，内置伙伴的名字和提示词改用繁体，不再显示简体（如「反馈助手」）。

### 同步自 RikkaHub

- 暗色模式下，搜索结果的引用角标改为实色背景，文字看得更清楚。
- 部分 OpenAI 兼容中转在回复中夹带空数据时，不会再中断整轮回复。
- 使用 Responses API 时，服务端已经执行过的工具会直接显示结果，不会在手机上再执行一遍。
- 修复用 Windows 换行符的消息里代码块无法正确结束的问题。
- 更新本地工作区的运行组件，修复 Ubuntu 26.04 中基础命令报「Security violation」无法使用的问题。
- 修复快速停止并重新开始生成时可能出现的闪退。
- 测试服务商连接时，推理设置改为与聊天默认一致的自动模式。
- 修复把会话移到文件夹时，会话恰好被打开后又回到原文件夹的问题。
- 万相（Wan）系列模型显示通义千问图标。

Updates:

### Miffan changes

- Terminals now show and accept Chinese text. Connections to remote computers use UTF-8 automatically, so Chinese file names and output no longer turn into garbage, and typing no longer brings up the system's English-only secure keyboard: your own keyboard works, and the remote terminal shows pinyin being composed at the cursor.
- Terminals look calmer: one monospace font, a soft dark color scheme, and text that no longer touches the screen edge.
- High-performance mode adds a Custom picture level that combines 720p to 4K with 30 to 120 fps (such as 1080p at 30 fps). A size larger than the computer's screen is lowered to fit.
- In professional mode, editing a computer now lists all of its addresses (network, last used, remove, add). Changes apply at once and keep the trusted computer identity, and computer cards show the address tried first plus how many others there are.
- With a Traditional Chinese system language, the built-in partners' names and prompts now use Traditional Chinese instead of Simplified (for example, the bug reporter).

### Synced from RikkaHub

- Citation badges in search results use a solid background, so they are easier to read in dark mode.
- Empty data sent by some OpenAI-compatible relays no longer cuts off a reply.
- With the Responses API, tools the server already ran show their result instead of running again on the phone.
- Fixed code blocks not closing in messages that use Windows line endings.
- Updated the local workspace runtime, fixing basic commands failing with "Security violation" on Ubuntu 26.04.
- Fixed a possible crash when stopping a reply and quickly starting a new one.
- Provider connection tests now use automatic reasoning, the same default as chats.
- Fixed a conversation going back to its old folder when it was opened while being moved.
- Wan series models show the Qwen icon.

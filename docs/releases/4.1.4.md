更新内容：

### Miffan 自有改动

- 应用内更新改为由 Miffan 自己下载安装包，不再调用系统下载管理器，修复部分手机上点击下载后立即报错、无法更新的问题。下载会使用应用里设置的代理。
- 更新卡片直接显示下载进度，可随时取消；下载完成后点按即可安装，停留在更新详情页时会自动打开安装界面。通知栏同样显示进度，下载完成后点按通知也能安装。
- 安装包下载后会校验 SHA-256、文件大小和包名；某个下载源失败或校验未通过时，自动改用下一个源。下载失败时会说明原因（网络、校验、存储空间），并可一键重试。
- 首次通过应用内更新安装时，系统会请求“安装未知应用”权限。

Updates:

### Miffan changes

- In-app updates now download the APK inside Miffan instead of through the system download manager, fixing phones where tapping download failed immediately and updating was impossible. Downloads use the proxy set in the app.
- The update card shows download progress and can cancel at any time; when the download finishes, tap to install, or the installer opens by itself if you stay on the update details. The notification shows progress too, and tapping it after the download also installs.
- Each downloaded APK is checked against its SHA-256, size and package name. If a source fails or the check does not pass, the next source is used. A failed download says why (network, verification or storage) and can be retried with one tap.
- The first in-app update install asks for the system "Install unknown apps" permission.

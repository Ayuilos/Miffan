更新内容：

### Miffan 自有改动

- 伙伴的小电脑现在也能放在 Windows 电脑上：由 Docker Desktop 运行，可以在手机上一步步装好。下载和安装在电脑后台进行并显示进度，离开页面也不会中断；需要管理员账户、登录桌面或重启电脑时会直接告诉你。
- 一台电脑存了好几个地址（比如家里的局域网和 Tailscale）时，连不上一个就自动换下一个，不再一直卡在连不上的那个地址上；手机上开着代理或 VPN 应用时也一样。
- 连接中途卡住时，会提示「电脑没有及时响应」，再试一次就会换一条新连接，不再误报脚本安装失败。
- 查看屏幕时，屏幕下方显示最新的聊天：在下面输入框里和伙伴聊的内容也会出现在这里，并自动停在最新一条。
- 在 Windows 电脑上安装或更新 Miffan 脚本时不再偶尔卡住。
- 连接 Windows 电脑时，输入账户名不会每打一个字就去尝试连接、收起键盘。
- 删除一台从没连上过的电脑时，会给出能在那台电脑上运行的删除钥匙命令（Windows 电脑给的是 PowerShell 命令），不再只闪过一句「尚未确认主机指纹」就没了下文。

### 同步自 RikkaHub

- 中转接口返回空的角色字段时，不再解析失败。
- 在俄语等用逗号作小数点的系统上，查询余额不再出错。
- 部分手机通过系统文件选择器导出文件时不再闪退。
- 聊天输入框的「+」面板在矮屏上可以滚动，下方的入口不会被挤出屏幕。

Updates:

### Miffan changes

- A partner's mini box can now live on a Windows computer too. It runs on Docker Desktop, which you can set up step by step from your phone. The download and install run in the background on the computer with progress shown, and keep going if you leave the page. If it needs an administrator account, a signed-in desktop or a restart, Miffan says so.
- When a computer has several saved addresses (say your home network and Tailscale), Miffan moves on to the next one when one does not answer, instead of retrying the unreachable one. This also works with a proxy or VPN app on your phone.
- When a connection stalls partway, Miffan says "The computer didn't answer in time", and trying again opens a fresh connection, instead of wrongly reporting a failed script install.
- The screen view now shows the latest chat under the screen: what you and the partner say in the box below appears there too, scrolled to the newest message.
- Installing or updating Miffan's script on a Windows computer no longer gets stuck now and then.
- When connecting a Windows computer, typing the account name no longer tries to connect, and closes the keyboard, after every letter.
- Deleting a computer that never connected now gives the command to remove the key on that computer (PowerShell for Windows), instead of a brief "Host fingerprint not confirmed" and nothing else.

### Synced from RikkaHub

- A relay that sends an empty role field no longer breaks parsing.
- Balance checks no longer fail on systems that use a comma as the decimal separator, such as Russian.
- Exporting a file through the system file picker no longer crashes on some phones.
- The chat input's "+" panel scrolls on short screens, so its lower entries are not pushed off.

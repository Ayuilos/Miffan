### Miffan 自有改动

- 伙伴之间可以私聊和群聊。伙伴能互相发消息，第一次联系需要你同意。你可以建群：主持的伙伴负责分工，被 @ 的伙伴同时回复，只有 @ 到你时才通知你。
- 聊天列表支持置顶头像和分组，长按即可整理。伙伴头像上新增状态灯：绿灯表示正在工作，黄灯闪烁表示在等你批准。
- 在对话里输入 @ 可以叫上其他伙伴，被 @ 的伙伴显示为头像标签，整体编辑。
- 经你同意后，伙伴可以修改自己的名字、头像和设定，头像可选内置形象，也能换回之前的头像，改动可以在修改记录里撤销。伙伴还能在你同意后创建新伙伴、建群、邀请伙伴和整理分组。
- 加强伙伴之间的权限隔离：
  - 伙伴只能回顾自己参与过的聊天，看不到其他伙伴的设定和私聊；
  - 由其他伙伴发起的回合里，伙伴的操作要你逐条批准，审批卡会说明原因。
- 新增「反馈助手」伙伴模板。它帮你排查问题，把 bug 整理成可复现的反馈，再由你在 GitHub 上提交。附带的报错摘要会先去掉密钥、地址等敏感信息。
- 简单模式新增后台助手：用一个轻量模型处理记忆、话题整理等后台任务，引导时会自动选好。在「我」页面可以查看它的状态和最近一次失败。
- 远程电脑支持 Windows：
  - 添加电脑时提供一键配置脚本；
  - 通过 Sunshine 查看屏幕，伙伴可以在电脑上执行命令和操作；
  - 通过 Tailscale 连不上时会说明可能的原因。
- 应用内更新改为由 Miffan 自己下载安装包：
  - 修复部分手机点下载后立即报错、无法更新的问题；
  - 显示下载进度，可以随时取消，并使用应用里设置的代理；
  - 下载后校验文件，失败时说明原因并可一键重试，某个下载源失败会自动换下一个；
  - 第一次安装时，系统会请求「安装未知应用」权限。
- 修复分享到 Miffan 的文字显示成乱码、用快捷方式拍的照片丢失的问题。

### Miffan changes

- Partners can chat privately and in groups. They can message each other, and the first contact needs your approval. You can create a group: the host partner splits the work, mentioned partners reply at the same time, and you are notified only when you are mentioned.
- The chat list supports pinned avatars and groups, organized with a long press. Partner avatars show a status light: green while working, blinking amber while waiting for your approval.
- Type @ in a chat to bring in other partners; a mentioned partner appears as an avatar chip that edits as one unit.
- With your approval, partners can change their own name, avatar and instructions. Avatars can be a built-in character or the previous one, and changes can be undone from the revision history. With your approval, partners can also create partners, create groups, invite partners and tidy up groups.
- Stronger isolation between partners:
  - A partner can only recall chats it took part in, and cannot see other partners' instructions or private chats.
  - In a turn started by another partner, each action needs your approval, and the card explains why.
- New "Bug reporter" partner template. It helps you troubleshoot, turns a bug into a reproducible report, and you submit it on GitHub. Attached error summaries have keys, addresses and other sensitive details removed first.
- Easy mode adds a background helper: a light model handles memory, topic sorting and other background chores, and onboarding picks one for you. The Me tab shows its status and its last failure.
- Remote computers now support Windows:
  - A one-step setup script is offered when you add a computer.
  - The screen shows through Sunshine, and partners can run commands and operate the computer.
  - When a computer can't be reached over Tailscale, the error explains the likely cause.
- In-app updates now download the APK inside Miffan:
  - Fixes phones where tapping download failed immediately and updating was impossible.
  - Download progress is shown, can be cancelled at any time, and uses the proxy set in the app.
  - Each download is verified. A failure says why and can be retried with one tap, and if one download source fails, the next one is tried.
  - The first install asks for the system "Install unknown apps" permission.
- Fixed shared text showing up garbled and photos from the camera shortcut being lost.

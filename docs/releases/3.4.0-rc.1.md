### Miffan 自有改动

- 新增远程工作空间，通过 SSH 连接服务器或已接入的 Tailscale 私网主机，支持多主机与多个项目目录。
- 支持远程文件浏览、编辑、导入导出，并可让 AI 在指定远程工作空间执行命令。
- 新增 SSH 密钥管理，支持生成、导入、复制公钥、查看私钥及加密导出，方便跨设备备份。
- 新增交互式远程终端，支持连续执行命令、实时输出、中文输入、快捷键和断线后重新连接。
- 简化工作空间管理界面，提供搜索、类型筛选和统一新建入口，并明确显示本地与远程身份及连接状态。
- 分开管理 AI Shell 使用权限与执行确认；切换工作空间或修改连接配置后，旧授权不能用于新的执行目标。
- 修复首次打开远程文件页偶发的连接报错，并改善终端输入法编辑与连接释放。

### Miffan changes

- Add remote workspaces over SSH for servers and hosts on an already connected Tailscale network, with multiple hosts and project directories.
- Browse, edit, import and export remote files, and let AI run commands in the selected remote workspace.
- Add SSH key management with generation, import, public-key copying, private-key viewing and encrypted export for cross-device backups.
- Add an interactive remote terminal with persistent shell state, live output, Chinese input, shortcut keys and manual reconnection.
- Simplify workspace management with search, type filters and a unified creation entry, while clearly showing local or remote identity and connection status.
- Separate AI Shell access from execution confirmation; previous approvals cannot authorize a new target after workspace or connection changes.
- Fix intermittent connection errors when first opening remote files, and improve terminal input-method editing and connection cleanup.

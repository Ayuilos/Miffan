### Miffan 自有改动

- 伙伴的小电脑：可以在你的 Mac 或 Linux 电脑上给每个伙伴一台独立的小电脑，伙伴在里面装软件、开浏览器、跑命令，碰不到你自己的桌面和文件。有轻量、标准、性能三档大小，之后能改。
- 准备小电脑很简单：在电脑页点「给伙伴一台小电脑」，不用先准备电脑桌面；缺 Docker 或磁盘不够时，会给出适合这台电脑的命令，可以直接在手机上运行。准备好后有几个「试试让它…」的例子，点一下就能开聊。
- 小电脑借用电脑本身的网络上网，电脑上开了代理（包括 Mac 的系统代理）也能用；连不上网时，可以在手机上一键修好，伙伴也会主动请你修。
- 收发文件：伙伴能把做好的文件交给你，放进电脑上的「Miffan Partners」文件夹，聊天里会出现一张文件卡片；你也能在手机上给小电脑传文件，或者下载、分享里面的文件。
- 查看屏幕重新设计：边框颜色告诉你现在谁在操作，屏幕下方按步骤列出伙伴在做什么。伙伴正在用时，点一下屏幕只会提示，再点一下才接管，不怕误触。横屏全屏时按钮放在两侧，聊天可以从侧边拉出来。
- 聊天里的电脑卡片：一次回复里的电脑操作合成一张记录卡，展开能看每一步；伙伴自己换办法解决的小失误不再标红；需要你同意的几步集中在一处，一次就能全部允许（之前一次允许多步时，只有最后一步生效）。
- 「我的电脑」改版：每台电脑分成「用桌面」和「小电脑」两部分，一眼看到哪些伙伴在用；小电脑的页面能看到最近的屏幕画面、是否在运行、内存和 CPU，以及最近收发的文件。
- 小电脑里的中文正常显示，窗口标题不再乱码；网页视频也能播放。
- 等回复时状态更准确：会分清「没有网络」「正在连接」「连接有点慢」和「思考中」。
- 修复电脑终端里弹出键盘后连接断开、按键没反应的问题；在终端里输入 sudo 密码时不再弹出输入法联想。

### Miffan changes

- A mini box for your partner: give each partner its own separate computer on your Mac or Linux computer. The partner can install software, open a browser and run commands there without touching your own desktop or files. Choose Light, Standard or Performance size, and change it later.
- Setting up a mini box is simple: choose "Give a partner a mini box" on the computer's page, with no desktop setup needed. If Docker is missing or the disk is low, Miffan shows the right command for that computer and can run it from your phone. When it is ready, a few "Try asking it to…" examples start the chat with one tap.
- The mini box goes online through the computer's own network, including a proxy set on it (such as a Mac's system proxy). If it cannot get online, fix it from your phone with one tap, and the partner will ask you to when it needs to.
- Swap files: the partner can hand you finished files in the "Miffan Partners" folder on your computer, shown as a file card in the chat. You can also send files to the mini box from your phone, or download and share what is inside.
- A redesigned screen view: the frame color shows who is in control, and the steps the partner is taking are listed under the screen. While the partner works, one tap on the screen only asks; a second tap takes over, so a stray touch never interrupts. In full-screen landscape the buttons sit at the sides and the chat slides out from the edge.
- Computer cards in chat: one reply's computer work becomes a single record card you can expand step by step. Small slips the partner worked around are no longer shown in red. Steps that need your OK are gathered in one place and can all be allowed at once (before, allowing several steps together only kept the last one).
- My computers is redesigned: each computer shows "Uses the desktop" and "Mini boxes", so you can see which partners use what. A mini box's page shows its latest screen, whether it is running, memory and CPU, and recent files.
- Chinese text shows correctly in the mini box, including window titles, and web videos play.
- Clearer waiting status: replies now tell "No internet connection", "Connecting…", "Slow connection…" and "Thinking…" apart.
- Fixed the computer terminal disconnecting, with keys doing nothing, once the keyboard opened; typing a sudo password there no longer brings up keyboard suggestions.

### Miffan 自有改动

- 开启高性能模式不再需要输入 PIN：Miffan 会直接让电脑信任这部手机，Linux、Mac 和 Windows 都支持。少数做不到的情况才会改用 PIN，并说明原因；电脑上正有人串流时，会先问你是否打断。
- 修复 Mac 上开启强制加密、解除配对时 Sunshine 无法正常重启的问题。
- 修复 Windows 电脑配对完成后，下一步仍提示「请先连接并准备好这台电脑」、打不开屏幕的问题。
- 轻松聊天模式里，伙伴请求在电脑上执行终端命令时，会直接打开终端卡片，点「允许」后命令能正常运行。
- Windows 电脑上通过屏幕输入文字更可靠：剪贴板没有真正写入时会改用备用方式。
- 修复对话刚开始生成就出错或被取消时，应用偶尔闪退的问题。

Updates:

### Miffan changes

- Turning on high-performance mode no longer needs a PIN: Miffan gets the computer to trust this phone directly, on Linux, Mac and Windows. Only in the few cases where that cannot be done does it fall back to a PIN, and it says why; if someone is streaming from the computer, it asks before interrupting them.
- Fixed Sunshine not restarting properly on a Mac when requiring encryption or unpairing.
- Fixed a Windows computer still saying "Connect and prepare this computer to open its screen." after pairing, so its screen would not open.
- In easy chat, when a partner asks to run a terminal command on the computer, the terminal card now opens in place and "Allow" runs the command.
- Typing on a Windows computer's screen is more reliable: when the clipboard was not actually written, Miffan falls back to another way.
- Fixed an occasional crash when a reply failed or was cancelled right as it started.

### Synced from RikkaHub

- No user-facing changes in this release.

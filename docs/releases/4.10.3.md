### Miffan 自有改动

- 中转支持 UDP 加速与自动回退：连接支持 HTTP/3 的中转服务时，Miffan 会优先使用基于 UDP（QUIC）的低延迟通道并减少连接耗时，在 UDP 受限的网络下自动切换回 TCP，完全兼容旧版中转服务。
- 加速组件按需获取，不增大安装包：使用中转功能时才会在后台按需下载并校验所需的网络加速组件，应用安装包体积保持不变，未使用中转的用户不受影响。
- 电脑端中转程序升级至 1.3.0：同步支持 UDP（QUIC）双栈传输与自动回退；在家直连电脑时 Miffan 会在后台自动完成更新，「经中转连接」引导命令也会默认安装新版。

### Miffan changes

- Faster relay with UDP acceleration and fallback: When connecting through an HTTP/3-capable relay, Miffan prefers a lower-latency UDP (QUIC) path for quicker connections and automatically falls back to TCP on networks where UDP is restricted, staying compatible with existing relays.
- On-demand component without increasing APK size: The network acceleration component is downloaded and verified in the background only when relay is used, keeping the app download size unchanged for users who do not use relay.
- Computer relay connector updated to 1.3.0: Adds the same UDP (QUIC) dual-stack transport and automatic fallback; Miffan updates installed computers automatically in the background over a direct local connection, and the "Pair via relay" setup command installs the new version by default.

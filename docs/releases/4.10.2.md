### Miffan 自有改动

- 无需直连即可经中转配对电脑：添加电脑时可直接选择「经中转连接」，在同网段外通过一行命令引导脚本或手动安装 `miffan-connector` 完成配对；支持展示本机设备公钥与 Miffan SSH 公钥，并在首次连接时通过中转核对 SSH 主机指纹。
- 纯中转电脑与专业模式配对支持：专业模式添加远程主机支持选择「通过中转」并填入 `hostId` 或 `miffan-pair://` 配对码，保存和编辑连接时可移除最后一个直连地址、仅保留中转路由。

Updates:

### Miffan changes

- Pair via relay without direct SSH: Choose "Pair via relay" when adding a computer to pair outside the local network using a one-line setup script or a manually installed `miffan-connector`, with copyable phone device and SSH public keys plus SSH host key fingerprint verification over the relay.
- Relay-only hosts and Pro Mode support: Adding a remote host in Professional Mode now supports "Via relay" with a `hostId` or `miffan-pair://` pairing code, and saved hosts with a relay route allow removing all direct addresses.

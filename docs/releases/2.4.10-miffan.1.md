安装说明:

> Miffan 的应用 ID 为 `me.ayuilos.miffan.app`，与上游 RikkaHub 相互独立，因此两者可以同时安装，不需要卸载旧应用。
>
> 两个应用的数据、设置和权限不会自动共享。如需迁移已有内容，请先在旧应用中导出备份，再在 Miffan 中导入。
>
> 后续 Miffan 版本必须继续使用相同证书签名，才能直接覆盖升级现有的 Miffan 安装。

Installation notes:

> Miffan uses the application ID `me.ayuilos.miffan.app`, independently from upstream RikkaHub. Both apps can be installed at the same time, so the existing app does not need to be removed.
>
> Their data, settings, and permissions are not shared automatically. To migrate existing content, export a backup from the old app and import it into Miffan.
>
> Future Miffan releases must continue using the same signing certificate to upgrade an existing Miffan installation in place.

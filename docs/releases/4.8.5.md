更新内容：

### Miffan 自有改动

- 翻译页可以直接换模型：顶栏显示当前的翻译模型，点一下就能换；已经有译文时，会用新模型重新翻译一遍。
- 翻译时不再闪出提示词：刚开始翻译的那一下，译文区域不会再短暂显示内部提示词。聊天里翻译消息也一样。
- 画图页可以直接换模型：顶栏显示当前的画图模型，点开就能换，伙伴画图也用这个模型。
- 翻译页和画图页改用图标按钮：粘贴、清空、翻译、复制、朗读、相册、参考图和保存都换成了图标，长按能看到文字说明。翻译时按钮上有进度环；画好的图右下角点一下就能保存。

### 同步自 RikkaHub

- Android 17 提醒开启本地网络权限：没有这个权限时，连不上局域网里的电脑和自建服务。设置页和「我」页顶部会提示，点一下就能授权。
- 搜索模型支持多个关键词：用空格隔开，不分先后，按模型名称或 ID 匹配。
- Tinyfish 搜索结果更准：搜索时可以带上搜索目的，让结果更贴合需要。

Updates:

### Miffan changes

- Switch models on the translate page: the top bar shows the translation model, and a tap switches it; if there is already a translation, the new model translates it again.
- No more prompt flash while translating: right as a translation starts, the result area no longer briefly shows the internal prompt. The same goes for translating a message in a chat.
- Switch models on the drawing page: the top bar shows the drawing model, and a tap switches it; partners draw with the same model.
- Icon buttons on the translate and drawing pages: paste, clear, translate, copy, read aloud, album, reference images and save are now icons, with their names on long press. The translate button shows a progress ring while it works, and a tap on the corner of a finished picture saves it.

### Synced from RikkaHub

- Local network permission reminder on Android 17: without it, Miffan cannot reach computers and self-hosted services on your local network. Settings and Me now show a reminder at the top, and a tap grants it.
- Model search with several keywords: separate them with spaces, in any order, to match a model's name or ID.
- More relevant Tinyfish searches: a search can say what it is for, so results fit better.

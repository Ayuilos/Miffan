# 伙伴对 App 环境的感知与修改能力清单（2026-10-12）

目标（主人定）：
1. 对齐通用标准，方便以后接入新东西；
2. 把 App 自身功能开放给伙伴，让它能感知和修改所处的环境。

不做自我扩展平台，也不新增执行环境。修改沿用现有机制：
- 主人发起（`ownerTrigger`，或引用主人原话）；
- 审批卡；
- 修订历史（`RevisionOrigin`）。

## 一、现状

| 领域 | 伙伴现在能看到 | 伙伴现在能改 | 缺口 |
|---|---|---|---|
| 自己的身份 | 系统提示词和学到的偏好（作为 prompt 本身） | 学到的偏好（`update_my_preferences`，需引用主人原话）；打开联网搜索（`request_web_search`，审批卡） | 不知道自己的名字、头像、模型、开了哪些能力；不能改名字、头像、提示词 |
| 扩展资源（快捷消息、模式注入、世界书、MCP、本地工具、工作空间绑定） | `extensions_catalog`，但**需要主人先给该伙伴打开“扩展管理”**，默认关闭 | 预览后经审批应用：新建或修改快捷消息、模式注入；绑定或解绑；设置工作空间；开关本地工具和联网搜索 | 不能删除；不能增改 MCP 服务器定义；不能安装 skill；凭据一律不可见（这是正确的） |
| 其他伙伴 | `list_contacts`：名字、系统提示词首行、是否已授权、是否同群 | 只能 `send_message`；主人 @ 时当轮免审批 | 不能新建伙伴；不能改联系授权 |
| 群聊 | 只知道当前所在群的成员 | 无 | 看不到群列表、自己在哪些群；不能建群、拉人、退群 |
| 消息列表（分组、置顶） | 无 | 无 | 完全不可见 |
| 聊天记录 | `conversation_search`、`recent_chats`、`read_partner_chat`（需开启“最近聊天参考”）；IM 主线有早期对话摘要 | 无 | 不能改标题、收藏、删除 |
| 记忆 | `memory_tool` 读 | `memory_tool` 增删改 | 基本够用 |
| Skills | `use_skill` 读取已启用的 skill | 无 | 不能安装或编写 skill |
| 工作空间和电脑 | 文件读、URL 抓取；电脑画面 | 写文件、shell、发布文件；电脑操作 | 已经比较完整 |
| 手机能力 | 时间、剪贴板读、日历查询、屏幕使用时间 | 剪贴板写、新建日历、朗读、执行 JS、向主人提问 | 每项都要主人在伙伴设置里单独打开 |
| App 使用帮助 | `miffan_help`：官方文档 | 无 | 只能看文档，不能看“当前实际设置” |
| 全局设置（模型、提供商、主题、语音、网络、备份、Web 服务） | 无 | 无 | 有意不开放的部分见下文 |

## 二、建议开放（按优先级）

### P1 感知：只读，低风险，收益最大
- **`my_environment`**，一个只读工具，返回：
  - 我的名字、头像、当前模型名；
  - 我开了哪些能力、绑定了哪个工作空间和电脑；
  - 我在哪些群、群成员是谁；
  - 记忆和最近聊天参考的开关状态。
- **IM 模式下默认提供只读的扩展目录**（`extensions_catalog`）；写操作仍然受“扩展管理”开关和审批的约束。

### P2 修改自己：审批卡 + 修订历史
- 改自己的名字、头像、系统提示词。复用 `extensions_preview_changes` 和 `extensions_apply_changes` 的预览、审批流程，新增变更类型。

### P3 修改周边：审批卡 + 修订历史
- 新建伙伴：名字、提示词、模型、能力，以审批卡呈现完整预览。
- 建群、拉人进群、自己退群。
- 消息列表：查看分组和置顶；新建或重命名分组、移动聊天、置顶或取消置顶。
  - 可撤销、低风险，可以只要求主人发起，不弹审批。

### 有意不开放
- 提供商、API key、代理等凭据；
- 网络设置；
- 备份和恢复；
- Web 服务；
- 任何删除操作。删除先不开放，以后再单独评估。

## 三、标准对齐（单独排期）

- **Agent Skills**：
  - 目前只解析 `name`、`description`。
  - 补齐规范中其余的可选字段（`license`、`compatibility`、`metadata`、`allowed-tools`）：能读取，并在界面上展示。
  - 增加命名规则校验。
- **MCP**：
  - 当前 Kotlin SDK 是 0.15.0，协议支持到 2025-11-25。
  - 2026-07-28 无状态版等官方 Kotlin SDK 跟进后再升级，现在只记录这项待办。
- **Agent Plugins**：导入时识别通用插件包里的 skills 和 MCP 配置。优先级低。
- **可选：把 P1–P3 的工具按 MCP 工具格式描述**，以后可以经现有的 Web 服务暴露给电脑上的 agent。本轮不做。

# 原生远程工作空间开发计划

## 目标与边界

将远程机器作为与本地 PRoot 工作空间并列的执行环境。Android APP 直接通过 SSH/SFTP 连接远程机器；不通过 PRoot、手机系统 SSH 命令或 Skill 建立连接。Tailscale 等私网由操作系统提供网络可达性，APP 不接管 VPN。

第一版支持 Unix/Linux SSH 服务、多主机管理、同主机多个工作目录、助手绑定、远程文件浏览/读写/导入导出和 AI 命令执行。Skill 是任务说明，不承担连接配置。远程常驻 Agent、手机离线后的自主任务、远程 Skill 安装/发现和自动发现 Tailscale 设备属于后续阶段。系统文件管理器的本地 SAF 入口不展示远程空间，远程文件通过 APP 内浏览器访问。

## 并行任务与负责人

所有执行子代理均使用 GPT-5.6 SOL，思考强度 xhigh（极高）。主代理负责整合、兼容性审查与最终验证。

| 阶段 | 子任务 | 负责人 | 交付与依赖 |
| --- | --- | --- | --- |
| 1 | 原生 SSH/SFTP 传输 | remote_transport | workspace 模块的连接、指纹发现和校验、命令与文件接口；先约定接口 |
| 2 | 数据与路由接入 | data_integration | 主机记录、加密凭据、数据库升级、本地/远程分流；依赖阶段 1 接口 |
| 3 | 管理界面与 AI 工具 | remote_ui | 主机管理、明确的指纹信任步骤、远程空间创建/绑定/浏览、工具与提示适配；依赖阶段 2 接口 |
| 4 | 整合与验证 | 主代理 | 审查 Skills/系统文件提供器/备份等本地假设，运行针对性测试与构建，记录无法验证的部分 |

## 设计要求

- 主机与工作空间分离：主机保存连接身份，工作空间绑定主机和绝对工作目录。
- 凭据使用 Android Keystore 支持的加密存储，不进入 Room、日志、模型上下文或可移植备份。
- 首次连接显示主机密钥指纹，由用户明确信任；密钥变化必须阻断连接，不能自动接受。
- 命令、文件和当前目录采用一致的远程路径约定。不得仅替换 Shell 后端而继续读取本地文件，也不得通过替换命令文本伪造路径挂载。
- 远程工作目录是组织边界，不是 SSH 账户的安全沙箱。绑定同一远程目录的助手共享内容，不继承本地私有 scope 的隔离承诺。
- 删除远程工作空间仅删除 APP 配置，不递归删除服务器目录。删除仍被引用的主机应阻止或明确处理引用。
- 连接失败、超时、取消、断网应明确返回，不回退到本地执行；不自动重试可能已经执行的远程写操作或命令。
- 保持本地工作空间数据、绑定、审批、Rootfs 和终端行为兼容。

## 验收

1. 无需安装本地 Rootfs 即可创建并使用远程工作空间。
2. 两台主机及同机两个目录可区分、切换，AI 能看到目标身份与工作目录。
3. 文件工具与命令操作同一目标；文件预览、编辑和结果发布不读取错误环境。
4. 未信任主机和指纹变化被拒绝；凭据不出现在数据库、提示和导出中。
5. 本地到远程、远程到本地切换无隐式文件迁移或本地回退。
6. 定向 JVM 测试与 Android 编译通过；有条件时通过 SSH 测试服务器检验端到端读写与执行。
7. 没有真实手机/Tailscale/用户服务器验证条件时，交付中明确列出待实机验收项。

## 后续开发顺序

### 本地 / 远程区分实施分工

依据 [区分研究](REMOTE_WORKSPACE_DISTINCTION_REVIEW.md)，2026-09-17 用户授权分派实施；三个子任务继续使用 GPT-5.6 SOL / xhigh。

| 子任务 | 执行者 | 交付与验收 |
| --- | --- | --- |
| 审批目标绑定 | data_integration | APP 保存原始目标快照，审批/执行复核；目标或权限版本变化使旧调用失效；持续授权精确绑定目标；切换/重配/禁用回归测试 |
| 连接状态模型 | remote_transport | 主机与目录状态分离，按需连接活动和最近结果；普通操作更新状态；命令失败不等于断线；固定执行配置和版本校验 |
| 身份展示与权限界面 | remote_ui | 本地/远程图标和分组，聊天/选择器/详情身份一致，审批历史显示原目标；Shell 能力与审批开关分开 |
| 整合与验证 | 主代理 | 数据库连接版本迁移、能力模型兼容、仅文件提示、接口协调、汇总构建和竞态/迁移/界面验证 |

先落实目标快照、连接版本与状态接口，再接 UI；合并后统一验证，不由各子任务并行运行 Gradle。

本轮实施与整合已完成。最终验证：ai 207、workspace 109、app 420 项 JVM 测试全部通过（共 736 项）；APP 和 Android 测试 APK 构建成功；Android 35 模拟器 9 项定向测试通过，含 Room 27→28 迁移、改名不换连接版本/账户变更换版本、远程身份与独立 Shell 开关、既有密钥和指纹流程。已检查身份/权限截图。源码同步复核中编译、测试及 APK 均为最新结果。

目标拦截测试覆盖 A→B、A→B→A、同主机 ID 改连接版本、Shell 关闭后重新开启、旧调用无快照和非工作空间工具兼容；状态测试覆盖旧连接迟到、目录故障与主机故障分离及新失败覆盖旧成功。未使用用户服务器或真实 Tailscale 私网，真实手机网络切换及长时间任务仍需实网验收。

### 已补充：SSH 密钥管理与认证可发现性

- `remote_ui`：将认证方式改为显式单选项；工作空间页提供独立密钥管理入口，支持生成、文件或文本导入、复制公钥、导出 `.pub`、重命名和删除。添加主机过程中创建密钥后保留主机草稿。
- `data_integration`：Room 26→27 迁移、独立加密私钥存储、多主机关联、使用中删除保护和备份恢复后的材料缺失处理。
- 主代理：离线 Ed25519 生成、带口令 OpenSSH/PEM 导入、密钥配对校验、公钥指纹计算，以及禁止密码登录的 SSH 测试服务器验收。
- 首次授权顺序：离线准备密钥 → 复制公钥 → 使用已有服务器访问途径安装公钥 → 在主机配置中选择该密钥。无需先通过密码登录。

### 工作空间 UX/UI 简化

用户追加授权后，三个 GPT-5.6 SOL / xhigh 子任务完成以下分工，主代理统一整合与验证：

- `remote_ui`：工作空间/连接主页、搜索和类型筛选、主机/密钥管理、简洁列表及空态，保持创建草稿。
- `data_integration`：详情默认文件、连接详情渐进展开、失败恢复入口及聊天选择器搜索。
- `remote_transport`：远程创建与主机验证弹窗，添加/验证主机往返保留输入、阶段状态及失败重试。
- 主代理：聊天侧栏直达入口、流程与兼容审查、设计和使用文档、统一构建与模拟器验收。

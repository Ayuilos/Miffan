# 远程工作空间连接与会话管理开发计划

基线：3.4.1。目标：首次使用时连接，使用期间复用，空闲后释放；明确区分真实连接状态和历史检查结果。当前每次文件/AI 操作独立连接并在 finally 关闭，终端连接归页面所有。

## 交付范围

1. **连接所有权与复用**
   - 增加应用进程范围的连接管理器，使用可取消的 lease/引用计数管理连接；UI 和 Repository 不直接拥有共享连接的关闭权。
   - 首期以工作区 ID、主机 ID、connectionRevision、远程路径组成连接身份，复用同一工作区的 SSH 连接；不强求跨工作区共享底层连接，避免改变目录隔离边界。
   - 合并并发建连请求；文件和 exec 使用各自通道，禁止并发共享可变 SFTP channel。取消单次操作只关闭该操作通道，不误伤其他操作。
   - 凭据、主机指纹、账户、端点、工作区路径变更，或主机/工作区删除时，立即使旧连接失效；保留现有目标快照和权限复验。

2. **生命周期与恢复**
   - 打开已配置的远程工作区时预连接；文件操作和 AI 工具都通过连接管理器取得 lease。
   - 可见工作区、进行中的操作和打开的终端持有使用引用。无引用连接默认闲置 5 分钟后回收；定时器、连接工厂和时钟可注入以测试竞态。
   - 保活只用于检测连接失效，不把旧的成功记录当作在线证明。断线后当前操作明确失败，下次操作允许重新建连。
   - 仅对尚未派发操作的建连阶段进行有界恢复；禁止自动重放命令、写入、重命名和删除。已派发操作遇断线保留“结果未知”。不静默重放终端输入。
   - 手动断开必须覆盖所有该工作区 lease，并抑制仍可见页面立即自动重连；下次明确连接/操作才恢复。重连期间避免无限循环。
   - 本期不引入永久后台服务、唤醒锁或进程被系统终止后的会话恢复承诺。

3. **终端会话保留**
   - 将 SSH PTY、输入/输出读取和终端模拟状态移出页面生命周期，由应用范围的会话所有者管理。
   - 页面导航、配置变化后重新附着到同一会话；保留有界滚动历史，避免重复读取、重复发送和 Activity/View 泄漏。
   - 关闭终端、主动断开、目标变更或进程结束时释放。网络断线后新建 PTY 不得冒充原会话恢复；提示会话已结束并提供新建连接入口。

4. **UI 与多语言**
   - 主要状态：未连接、连接中、已连接、重连中、连接失败；操作状态与连接状态分开。
   - 在工作区详情提供简洁的连接/断开/重连入口；列表和聊天入口消费同一状态源，不能由历史检查记录推导“已连接”。
   - 主机级状态与工作区级目录状态保持区别；多个工作区共享主机时不误报其他工作区的连接状态。
   - 保留当前极简风格；连接权限与 AI Shell 执行授权继续分开。
   - 所有新增/修改文案通过 locale-tui 写入英语、简中、繁中、日语、韩语、俄语，遵循本仓库 localization skill。

## 实施顺序

先实现并测试连接管理器与 transport 通道取消语义，再接入 Repository 和状态流；随后迁移终端所有权、接入 UI 与六语言资源，最后做整体验证。必要时适配现有运行时 tracker，避免并存两个相互矛盾的在线状态源。

## 验收

- 连续列目录、读文件和 AI 操作复用同一工作区连接；并发首次访问只创建一个连接。
- 单操作取消不影响并发操作；空闲计时不会关闭仍有使用引用的连接；手动断开和配置失效不存在旧回调覆盖新状态的竞态。
- 主机/密钥/路径修订后旧连接不可复用，原权限快照检查仍有效；不同目录不串用。
- 网络断开可被检测，下一次操作能重连；已派发命令与写入不自动重试，结果未知状态正确。
- 终端切出再返回保留会话与输出，尺寸变化能恢复；显式关闭释放资源，断线不会重复发送输入。
- 列表、详情、聊天入口状态一致；六语言切换无遗漏、格式参数正确。
- 运行相关 JVM 与 UI 回归测试，覆盖原目录返回、主机验证、SSH 密钥、Shell 权限；完成完整 test/lint/assembleDebug。需要真实 SSH 集成时使用一次性本地测试服务，不使用用户服务器或私钥。
- 更新 docs/REMOTE_WORKSPACE.md 对连接生命周期和终端边界的说明；不做无关数据库迁移，不修改版本号，不发布 Release 或删除任何云端资源。

## 执行与交付

实现交由一个 GPT-5.6 SOL、high reasoning 子任务完成。使用 codex/remote-workspace-session-lifecycle 分支，按可审查步骤提交。交付代码、验证结果、限制和未解决问题；由主任务审阅最终差异和边界行为。计划中的默认值可在实现中基于证据调整，但必须记录理由。

# P4 UI 实现说明

## 已完成

- 按要求将 `feature/remote-screen-ui` 重建到 `feature/remote-screen` 的 `c281e29a`，完整阅读 P4 规格、总计划、P3 说明及两个现有接口的 KDoc 后实现。新增 `Screen.PartnerScreen(assistantId)` 和 `Screen.ComputerSetup(assistantId)`。
- 轻松模式聊天右上角按 `PartnerComputer.showsEntry` 显示电脑入口；无入口时保留伙伴资料入口。资料页增加“操作电脑”、电脑名、开启确认、逐步询问开关、查看屏幕及重新检测/更换入口，写入沿用 `ImPartnerVM.update`。开启说明复用专业模式的授权内容。
- 伙伴屏幕页复用现有画布、键盘和控制权横幅，提供连接状态、流量、触控模式、重连及 Esc/Tab/Enter。失败面板抽出可复用版本，专业模式只改调用位置，保留默认文案与行为；轻松模式改用电脑措辞并进入接入引导。
- 对话区显示最近回复的两行、实时生成状态或当前电脑动作，点击进入聊天并定位消息；待审批卡片、错误重试和紧凑输入条使用同一伙伴的现有聊天服务。批准电脑操作前显式交还控制权，返回或转入引导时也交还。
- 对话内容独立于画布布局，最高为可用高度的 35% 且不超过 220dp，可滚动；输入法弹出时共同缩小布局。紧凑 `ThreadComposer` 隐藏附件、语音并限制两行，原聊天页默认行为不变。
- 仅 `computer_` 工具采用电脑卡片：进行中显示动作和最后一张截图，整卡进入屏幕；完成后保留操作证据、最后截图及屏幕入口，即使回复没有文本也保留。完成截图使用现有大图预览，进行中截图最高 160dp，摘要截图最高 64dp、最宽 96dp。
- 操作计数只包含成功执行的非观察步骤，排除查看、列表、指南、缩放观察、验证及拒绝/错误/未执行步骤；纯观察使用“看了看屏幕”。`refused` 显示接管停止提示，`error` 使用错误样式，卡片不展示堆栈。普通工具与服务端工具继续走原展示流程。
- 电脑审批显示专用动作、前台打断提示、允许/这次不要/查看屏幕及原始参数详情；重用 P3 的动作和状态解析。工具自带电脑快照时按历史电脑名展示，更换绑定后不把历史电脑入口导向另一台电脑。
- 接入引导覆盖 CHOOSE → ADDRESS → VERIFY → PREPARE → MAC_ACCOUNT（仅 Mac）→ TEST → BIND → DONE，调用现有 `ComputerSetupVM`。所有推进、信任、安装、保存账户、权限请求和绑定均由明确点击触发；任务期间显示进度、禁用操作和系统返回，错误在当前步骤中映射展示并可关闭。
- 地址支持密码及推荐的应用密钥，密钥选择/生成、公钥和授权命令复制；密码只保存在当前 Compose 内存中，不放入 saved instance state。配置已保存但指纹读取失败时，保留“重新读取指纹”操作并锁定地址字段，关闭错误提示也不会重复创建电脑。
- 指纹显示算法、SHA256、目标账户地址、核对命令及身份变化警告。准备页显示桌面/屏幕服务/可选剪贴板/cua-driver 检查，沿用 P2 Linux 安装指导；安装前展示完整命令、下载来源、默认匿名遥测和 Mac 权限说明，命令变化时要求重新确认，失败输出末尾可展开。
- Mac 账户支持读取并选择已保存账户，显式提交后保存。测试页按 workspaceId 获取屏幕 VM，复用实时可交互预览，重新进入测试时刷新会话；任务中屏蔽预览操作。伙伴检查显示权限缺失和远端授权说明、只读检查截图，通过后才能继续。
- 绑定展示伙伴/电脑名、截图提供商和账户权限说明、逐步审批及替换原绑定提示；完成页显示截图，“去聊天”仅预填“看看我的电脑屏幕上有什么”，不自动发送。
- 各种 VM 使用独立类型前缀 key，屏幕 VM 按规格使用 workspaceId；屏幕可见性、后台暂停和保持亮屏沿用专业页逻辑。画布沿用当前基线的首次触摸 `takeControl()`，包含黑边触摸。
- 新增 92 个字符串和 1 个 plurals，英文/简体中文共 93 组 `im_computer_` 资源。复数摘要使用 `pluralStringResource`；其余语言回退英文，沿用逐键 MissingTranslation 标注，无全局 lint 放宽。

## 没做与当前限制

- 未修改 `data/`、`service/`、`RemoteScreenVM.kt`、`ComputerSetupVM.kt`、`AgentThreadVM.kt`、workspace 模块、数据库或依赖注入；不新增控制权规则、审批策略或远端协议。
- 未连接远程机器、模型、模拟器或真机，未运行真实桌面操作。GNOME/KDE Wayland 的后续接入能力、既有聊天错误及工具队列由数据层处理。
- 普通返回保留原聊天页；点击屏幕页回复定位或完成页“去聊天”会移除该伙伴已有的 Thread 路由并建立带定位/预填参数的新路由，因此旧页面草稿和筛选状态可能重置。现有 Navigator 无法向已存在页面直接投递定位/草稿事件。
- 没有独立首次授权记录，每次从关闭到开启都会确认；审批偏好通过既有字段保存，关闭能力不修改偏好。
- 引导步骤来自现有 VM 内存状态，支持 VM 留存期间旋转，未新增进程死亡后的恢复。返回/退出引导不会删除已经创建的电脑、密钥或工作空间，遵循 VM 的现有保存行为。
- `computer_read_guide` 等缺少 `workspaceTarget` 的历史工具，名称回退到当前绑定电脑；缺少快照时无法可靠判断原电脑，不能完全保证更换绑定后的历史证据归属。含快照的工具已经限制入口匹配。
- 交还后的动作恢复时机与正在执行的动作收尾仍由现有数据层决定，controller 表示逐动作控制状态，并非整轮模型任务的持续进度。

## 需要主代理真机确认

1. 未绑定、本地绑定、远程但屏幕关闭、屏幕开启时的聊天与资料页入口；能力确认取消/开启、审批偏好持久化和不同伙伴隔离。
2. 屏幕画布的直触/触控板、键盘输入、剪贴板提示、按键菜单、流量和重连；黑边/按住立即接管、批准前交还、返回/进入引导/前后台切换及旋转。
3. 小屏、横屏和软键盘下画布与对话区不重叠；远端键盘和聊天输入的焦点切换；多个审批时滚动可达、状态变化及回复定位。
4. 混合普通工具/电脑工具、只读回复、无文本回复、失败/接管、长动作参数及多截图的展示；完成截图预览与历史电脑更换后的入口。
5. 新建和已有电脑的完整接入流程，指纹变化/读取失败/关闭错误后的重试，密码与密钥登录、复制命令、取消安装、安装失败尾日志及重新检测。
6. Linux 支持的 Wayland/X11 会话与不支持会话提示；Mac 屏幕共享账户、旧账户复用、权限弹窗在实时预览中处理、权限再次检查、伙伴截图与绑定替换。
7. DONE 去聊天预填但不发送、查看屏幕、返回步骤和退出后的已创建配置；进程被杀后重进的现有 VM 行为。

## 对接口的建议

- Navigator 可增加面向已打开 Thread 的消息定位和草稿投递接口，避免为传递参数重建聊天路由，保留原草稿、筛选及滚动状态。
- 建议所有 `computer_` 工具（含指南）都带执行时电脑快照，并提供稳定的 workspace/host 标识供屏幕入口匹配；当前缺失快照的历史证据只能回退名称。
- `PartnerComputers.observe` 的初始加载和“未绑定”都表现为 null，首次进入可能短暂显示连接引导；可增加 loaded 状态以区分。
- 引导可暴露可恢复的步骤与非敏感表单状态，明确进程重建后的继续策略；凭据继续留在受控保存接口内。可增加仅首次确认的授权版本记录。
- 若需要整轮任务的电脑操作持续状态或立即中止正在执行的操作，应由数据层提供与 controller 分离的状态/取消接口；本次 UI 只展示现有真实状态。

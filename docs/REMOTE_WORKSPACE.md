# 使用远程工作空间

从聊天侧栏进入“工作空间”，在“主机”添加远程主机，填写 SSH 地址、端口、用户名，并通过“认证方式”的单选项选择密码、已保存的 SSH 密钥或直接粘贴私钥。原扩展入口也可使用。手机已经接入 Tailscale 时，可填写私网 IP 或可解析的主机名；目标机器需要运行 SSH 和 SFTP 服务。

## 先准备 SSH 密钥

“工作空间 → 密钥”提供独立管理入口，不需要先保存主机或登录服务器。

1. 点击生成密钥并命名，APP 在设备上生成 Ed25519 密钥对；也可以导入已有的 OpenSSH / PEM 私钥，若有口令则填写口令。
2. 复制完整公钥，或导出 `.pub` 文件。公钥是一整行 `ssh-ed25519 ... miffan`（导入其他类型时前缀相应变化），不是 `SHA256:...` 指纹。
3. 通过已经能登录的电脑或服务器控制台，将公钥加入目标账户的 `~/.ssh/authorized_keys`。
4. 在 APP 添加或编辑远程主机，选择“SSH 密钥”，然后选择刚创建的密钥，再测试连接。服务器可以保持禁止密码登录。

一把密钥可绑定多台主机。列表提供重命名、复制公钥、导出公钥和删除操作；仍被主机使用的密钥不能删除。现有主机直接保存的密码或私钥仍然可用。

私钥加密保存在本设备。密钥菜单提供私钥查看与手动备份：默认隐藏，设备已设置锁屏时先验证设备身份；导出使用 OpenSSH 私钥格式，默认要求填写并确认加密口令，也可主动选择无口令导出。通过系统文件选择器指定保存位置，导出后可在其他设备导入。

私钥不包含在 APP 的可移植备份中；请单独保管导出的私钥文件和口令。恢复 APP 备份后，缺少私钥的条目会标记为待恢复。导入与其公钥匹配的原私钥即可恢复；无法取得原私钥时，需要生成新密钥并重新授权服务器。

## 添加主机与工作空间

添加后查看主机指纹，通过可信渠道核对，再点击信任并测试。主机密钥变化时，APP 会显示旧指纹和新指纹，需要明确确认。修改主机地址、用户名或凭据后，应重新测试连接。

新建远程工作空间时选择主机和已存在的绝对项目目录，例如 `/home/me/project`，不能直接选择 `/`。同一台主机可创建多个目录工作空间。随后在助手设置或聊天的工作空间选择器中绑定，AI 的命令执行和文件工具即作用于该远程环境。此过程不要求下载本地 Rootfs。

创建表单可直接添加主机或进入指纹确认，返回后保留名称和目录；添加成功的主机会自动选中。空间列表支持搜索和本地/远程筛选，进入详情默认打开文件，连接配置和权限在设置中按需展开。文件页连接失败时可直接重试或检查主机。

## 类型、连接状态与 AI 权限

工作空间列表使用不同图标与类型文字区分本地、远程，并提供类型筛选。远程列表项精简为名称、主机与状态，完整 SSH 账户、端口和目录在详情及工具审批中查看；聊天入口和选择器同样保留目标身份。

打开已配置的远程工作空间时会预连接。同一工作空间的文件操作、AI 工具和手动终端复用经过验证的 SSH 连接，各次文件操作和命令使用独立通道；前台可见页面或进行中的操作持有连接引用；普通文件页退到后台时释放页面引用，正在使用的终端和操作不受影响。没有引用的连接空闲 5 分钟后关闭。详情页可手动连接或断开；手动断开后，可见页面不会自行重新连接，下一次明确连接或操作才会恢复。连接状态反映当前进程持有的真实会话，最近检查与操作结果单独记录；重启 APP 后需要重新连接。不同工作空间即使使用同一主机，也各自验证目录并维护连接状态。

助手设置中的“允许 AI 使用 Shell”决定是否提供命令执行能力，关闭后仍可使用文件工具。“Shell 每次执行前询问”决定是否逐次批准，不能用它代替禁用 Shell。远程 Shell 使用 SSH 账户的实际权限；即使文件工具设为只读，也不能据此认为已允许的 Shell 命令只读。

工作空间工具调用会保存 APP 提供的原始目标快照。切换绑定、修改连接身份或撤销 Shell 能力后，旧调用不能转而执行到新的目标。缺少目标快照的历史未执行调用须重新发起。持续免审批仅对匹配的助手、空间与目标版本生效，审批卡和命令历史显示当时的目标。

## 文件与命令路径

APP 文件浏览器与文件工具提供 `/workspace` 别名，映射到选择的远程目录；文件工具也接受该目录下的真实绝对路径，匹配真实根目录的路径优先按真实路径解释。Shell 直接使用远程机器的路径，没有人为创建 `/workspace` 挂载。例如工作目录为 `/home/me/project` 时：

| 操作 | 路径或命令 |
| --- | --- |
| 文件工具读取 | `/workspace/README.md` 或 `/home/me/project/README.md` |
| Shell 读取 | `cat README.md` 或 `cat /home/me/project/README.md` |
| Shell 创建成果 | 在项目目录下创建文件后，调用 `workspace_publish_files` 发布 |

助手提示会自动说明目标主机、目录和路径规则。同一远程目录由绑定它的助手共享，远程 Shell 使用 SSH 账户权限；它不是本地助手私有 scope，也不是服务器安全沙箱。

## 手动远程终端

进入远程空间的文件页，点击顶部终端按钮，可直接使用 SSH 交互式 Shell。终端从配置的工作目录启动，同一会话内保留 `cd` 和环境变量，支持实时输出、手机键盘、方向键、Tab、Ctrl-C 和粘贴。无需安装本地 Rootfs，也不受助手的“允许 AI 使用 Shell”开关控制；实际权限由远程 SSH 账户决定。

点击返回只离开终端页面，工具栏的“断开”才会关闭终端。切换页面或旋转屏幕后，终端会话、屏幕和最多 2000 行滚动记录仍在当前 APP 进程内，返回时重新附着到同一 PTY。明确关闭终端、手动断开工作空间、修改目标或结束 APP 进程时释放会话。网络断线后显示会话结束，手动新建的 PTY 不会恢复旧 Shell 状态，也不会重放输入。断开连接不能保证服务器进程已结束，需要跨连接保留任务时可在服务器使用 tmux 等工具。

## 数据与连接行为

- 密码、私钥和私钥口令加密保存于 Android 的不可备份目录，密钥由 Android Keystore 管理。数据库只存连接配置和已信任指纹。恢复到另一台手机后，需要重新填写凭据。
- 删除远程工作空间只删除 APP 配置，不删除服务器目录。删除主机前需要先删除它关联的工作空间。
- 网络失败不会切换到本地执行。超时或取消会关闭 SSH 通道，但不能保证服务器上已经启动的进程停止；重新执行有副作用的命令前，应先检查远程状态。
- AI 工具的 Shell 命令有执行超时；手动终端保持到明确关闭或断线。远程文件操作连续 60 秒无进展会关闭该操作的 SFTP 通道并报超时，不会关闭同一工作空间的其他通道；上传和下载每次传输数据都会延长等待时间。元数据操作按整次操作计算等待时间。已派发的命令和写入不会自动重放，超时或断线后请先检查远程状态，再手动重试。
- 文件浏览/编辑拒绝工作目录内部的符号链接。选择的根目录可通过符号链接解析为真实目录。
- 文件覆盖先上传临时文件，再切换目标；普通上传失败不会先截断原文件。极端断线或崩溃发生在重命名过程中时，服务器上可能保留 `.miffan-backup-*` 恢复副本。
- 导入或下载到同名远程文件时会报错，不会自动覆盖；需要选择其他文件名。远程文件路径暂不支持 `* ? [ ]` 等会被 SFTP 库解释为匹配模式的字符。
- 本地工作空间的审批和数据保持兼容。远程主机身份变化时，相关工作空间需要重新测试，已有免审批设置也会重置。

## 新功能介绍

完成配置后，首次从启动器进入聊天页时展示一次「远程工作空间」介绍，说明 SSH / Tailscale 连接、文件与终端和 AI 协作，并提供工作空间管理入口。介绍不在外部分享、首次配置或数据库迁移期间展示；同次启动不会叠加旧的主题介绍。点击「稍后再说」、系统返回或弹窗外部关闭后不再提示，旋转屏幕保留当前弹窗。

展示记录使用独立的 `remote_workspace_intro_seen` 设置，不修改聊天数据或数据库结构。

## 第一版限制

当前支持 Linux/Unix 风格 SSH/SFTP 服务。远程 Skill 安装与发现、系统文件管理器里的远程 SAF 入口，以及手机离线后继续自主执行的远程 Agent 尚未提供。APP 不管理 Tailscale 登录或网络规则，也不自动发现私网设备。

远程文件补全只列出当前目录和项目根目录，不递归扫描整台服务器。

较长的工具输出会截断；远程空间不会在手机上创建伪造的本地 `/tool_outputs`。需要完整输出时，让 AI 将其保存到远程项目文件中，再读取或发布。

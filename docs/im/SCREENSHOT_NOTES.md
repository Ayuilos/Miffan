## 临时演示数据与 fixture

仅使用本任务创建的虚构配置和记录。六位伙伴名称、头像配色与碗内容严格按 SCREENSHOT_SPEC：Classic Rice、Matcha Sprout、Sakura Rice、Moonlight Stargazer、Sea Salt Rice、WhaleGirl。推荐伙伴未添加。

初始伙伴、昵称、默认模型及引导状态通过 `/tmp` 下的合成 Preferences DataStore 配置载入模拟器；这不是通过界面导入备份。没有直接写入聊天、记忆或修订数据库。为输入准确的中英文，临时安装本地输入法，将原台词原样提交给原生 Compose 输入框，并调用键盘发送动作。

OpenAI 兼容 fixture 只监听主机 `127.0.0.1:18766`，通过指定模拟器的 adb reverse 连接；API Key 为空。普通和流式回答逐字返回说明中的台词，快速模型按雨、菜、猫的主题返回分类 JSON。并发三问使用原生输入框发送，雨、菜、猫的回复分别延迟 18、20、30 秒，形成规定到达顺序及应用自动引用。输入中问题的顺序仍为雨、猫、菜。

`update_my_preferences` 提交完整偏好、简短摘要及用户原话；调用应用实际工具写入偏好，自动产生 Notice、baseline 和 agent 修订。`memory_tool` 以 create 动作逐条创建指定内容，应用保存来源伙伴、来源消息及创建日期。没有替换工具执行结果。

部分演示消息通过应用已有的 `/api/conversations/{id}/messages` 本地接口发送，接口调用原生 ChatService，再由 fixture 回复。接口仅监听模拟器本地回环，使用 adb forward 连接，未连接真实模型、账号或远程 API。不同画面使用独立的演示会话，避免无关台词混入；话题画面紧接并发画面，历史画面来自设定变更画面。

fixture、输入法、配置、原始 PNG 和操作脚本均保留在临时目录，不提交。

## 逐画面生成步骤

下表的每一行分别生成 `zh`、`en` 两套，均在同一页面切换系统浅色 / 深色后等待渲染稳定，原生截屏并无损转换为对应的两个 WebP 文件。文件名以 SCREENSHOT_SPEC 为准。

| 文件前缀 | 生成步骤与核验内容 |
| --- | --- |
| `01-chats` | 六位伙伴分别生成说明中最近消息；Miffan 在同一会话生成三条助手回复，海盐生成两条，抹茶生成一条后保持另一条请求等待。进入其他伙伴时间线标记已读，在消息列表左滑置顶 Miffan。核对 3 / 1 / 2 未读、正在输入、其余无未读及大肥鱼昨天标签。 |
| `02-thread` | 将模拟器日期设为前一天，发送第一句并等待回复；设为当天 21:03，在同一会话发送第二句。打开 Miffan，完整显示两轮对话及昨天 / 今天标签。 |
| `03-parallel` | 清理本任务的旧演示会话，原生输入框连续发送三个规定问题，等待 fixture 三个延迟回答完成，收起输入法；核对雨、番茄、猫的到达顺序及每条自动引用。 |
| `04-topic` | 长按上一画面团子回复，选择只看这个话题，通过应用标题接口将猫话题标题设为“猫的名字” / “Cat names”；在过滤状态发送规定追问，等待两段回答。 |
| `05-self-config` | 在干净的演示时间线发送规定的持久偏好请求；真实执行 update_my_preferences，等待通知和规定的确认回复出现，工具详情保持折叠。 |
| `06-history` | 从伙伴资料进入 Miffan 设定历史，展开上一画面产生的最新修订，选择原文差异，显示移除的空偏好和新增偏好。 |
| `07-memory` | Miffan 记录工作地点，樱花记录橘猫，Miffan 记录饮食偏好；按创建时间倒序显示规定的三条。通过我 → AI 对我的了解进入，核对内容、来源头像、伙伴名与日期。 |
| `08-partners` | 打开伙伴 Tab，保留顶部六个指定伙伴网格及未添加的推荐卡片，不添加任何推荐伙伴。 |
| `09-onboarding` | 使用无服务商配置的演示引导状态，打开 IM 引导第 1 步，仅选中 OpenRouter，不登录、不请求授权。 |
| `10-mode` | 在此模拟器安装已有的 3.4.4 release，载入虚构伙伴和服务商配置但不设置 interface_mode；启动旧版后覆盖安装本次 release，确认升级欢迎弹窗。为重拍语言和颜色组合，回放同一合成配置的 professional / choicePending 状态；选中轻松聊天，停在继续之前。 |
| `zh/01-chats-whale.webp` | 保留中文消息列表演示数据，将原生主题切换为 whale_girl，浅色重新打开列表并恢复抹茶等待请求，原生截屏。 |

## 当前实现与设计稿的必要差异

- 画面 04 的两句新名字在同一助手消息中分段显示；原生发送流程的一次完成回复对应一个 UIMessage。两句台词保持原样，没有把单条回答伪造为两个数据库消息。
- 画面 05 保留真实工具调用产生的“完成了 1 个步骤”折叠摘要。画面 06 的变更字段为“学到的偏好”，因为现有 update_my_preferences 更新 learnedPreferences，未改写 systemPrompt；原文差异真实显示空值到指定偏好。
- 画面 09 当前引导是 1/2，提供五种服务商卡片；设计稿为 1/3、三个卡片。选中 OpenRouter、未登录的状态一致，保留 release 原生布局。
- 画面 10 的旧调试包后缀为 .debug，无法覆盖 .app release，因此使用同签名的既有 3.4.4 release 执行真实覆盖升级。保留当前原生选项卡式弹窗及专业模式背景，未拼接设计稿缩略图。该升级只使用虚构演示数据。
- 主题色、头像背板、段落分组、菜单和工具摘要以当前 Material 3 实现为准，未为贴合设计稿修改代码或截图。服务商品牌（包括英文界面中的硅基流动）沿用应用原生标签。
- 英文画面 01 的 Miffan 最近消息在原生单行预览中显示省略号；实际回复仍完整为 `Eggs first, set them aside, then the tomatoes.`，没有缩短或改写台词。
- Android 35 状态栏演示保留原生 3G 标识；部分浅色页面的移动网络图标仍以浅色绘制，Wi-Fi、电量与时钟正常。保留系统渲染，不以修图改变图标。尝试超出 Wi-Fi 支持范围的信号级别曾使 SystemUI 重启，相关异常帧已弃用；最终使用支持范围内的 level 4。

# Miffan 4.0 收官版宣发截图拍摄说明（v5，草案）

2026-11-08 起草，供 4.10.0（4.0 收官版）使用，替换 `docs/img/v4/`。旧版说明见 `SCREENSHOT_SPEC.md`；自 10 月初以来伙伴页、引导、我、发现、电脑、屏幕页都已重做，旧图不再代表现在的样子。

执行前由总管确认本稿；执行中不要改写台词，确需调整写进 `docs/im/SCREENSHOT_NOTES_V5.md` 并说明原因。

## 产出

- 下表 14 个画面 × 中文 / 英文 × 浅色 / 深色；标「仅浅色」的画面只拍浅色。另加 1 张蓝色大肥鱼主题的消息页（中文浅色）。
- 1080 × 2400 原生截图，无损转 WebP，命名 `docs/img/v5/{zh|en}/{nn}-{slug}-{light|dark}.webp`。
- 不使用任何真实个人数据、真实 API Key 或真实账号；电脑相关画面用专门的演示电脑，主机名、用户名、路径都改成演示用的。

## 拍摄环境

- 模拟器 `Pixel_8_API_35`（1080 × 2400，420 dpi），只用一台；状态栏演示模式（时钟 21:03、满格、无通知），拍完关闭。
- 包：`me.ayuilos.miffan.app.bench`（调试签名、与正式版并存的基准变体，`./gradlew :app:assembleBenchmarkRelease`）。不显示「开发模式」标记，也不需要正式签名。测试数据接收器会清空数据，只在这个包上用。
- 语言：`adb shell cmd locale set-app-locales me.ayuilos.miffan.app.bench --locales zh-CN|en-US`。
- 深浅色：`adb shell cmd uimode night yes|no`；应用内「跟随系统」，关闭动态取色，主题用默认预设（大肥鱼图除外）。
- 模型回复：`scripts/perf/fake_llm.py` 的思路，另写一个只监听本机的演示用 fixture（按下文台词返回普通回复、话题分类 JSON 和工具调用），不提交进仓库。
- 数据：伙伴、记忆、收藏等可以先用 `PERF_FIXTURE` 灌入后再按下表通过界面或本地接口改成演示内容；画面里不能出现测试数据的痕迹（如 `BOB_BUSY`、`7303`）。

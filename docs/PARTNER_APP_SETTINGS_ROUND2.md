# 伙伴帮忙配置 App：第二轮（显示、语音、伙伴参数）

第一轮（AI 服务、模型、搜索、请求头、Key 安全卡片）见 `PARTNER_APP_SETTINGS_PLAN.md`。本轮沿用它的全部机制：改动走变更卡、可撤销；凭据走安全卡片、伙伴看不到；只在轻松模式、主人发起的回合提供。

原型：https://claude.ai/artifact/6iPR2hBaKerhSrP9X9Qc4D（2026-11-11，待确认）

## 目标

用户说"字太小了""换个暗一点的主题""用 ElevenLabs 给我读""小鲸回得太啰嗦，少想一点"，伙伴都能直接办，不用用户自己翻设置页。

原则：**只开放在轻松模式里真正生效的设置**。改了看不到效果的设置，不交给伙伴。

## 范围

### 1. 显示和通知

| 设置 | 伙伴怎么说 | 取值 |
|---|---|---|
| 字号 | "字调大一点" | 小 / 标准 / 大 / 特大（0.9 / 1.0 / 1.15 / 1.3 倍） |
| 主题 | "换个暗一点的颜色" | 预设主题之一，或跟随壁纸取色 |
| 数学公式 | "公式显示成乱码了" | 开 / 关 |
| 代码块 | "代码太长了折起来" | 自动换行、自动折叠，各开 / 关 |
| 回复完成通知 | "伙伴回完了提醒我" | 开 / 关 |
| 实时进度通知 | "别在通知栏一直显示" | 开 / 关 |
| 发图前裁剪 | "发图别每次都让我裁" | 开 / 关 |
| 你的称呼 | "以后叫我小陈" | 1–20 字 |

另外：深浅色（跟随系统 / 浅色 / 深色）和"深色时用纯黑背景"也开放。它们存在单独的偏好里，不在主设置中；伙伴改动时先记修订再写偏好，主人在外观页手动改也会记一版，撤销不会盖掉主人后来的改动。（方案初稿误写成"App 没有单独开关"，已更正。）

不在本轮：新建自定义主题（要选颜色，不适合在聊天里描述）；已有的自定义主题可以选。

### 2. 默认模型补全

在第一轮的默认模型里再加：
- **画图模型**：轻松模式"画图"和伙伴的 `generate_image` 用的那个（`imageToolModelId`）。可以清空，清空后画图入口提示未设置。专业模式画图页用的 `imageGenerationModelId` 不在本轮。
- **快速模型想多久再回**：沿用现有的四档"秒回 / 看情况 / 多想想 / 深思熟虑"，映射和伙伴资料页里的一致。

### 3. 伙伴的回复参数

主人可以让伙伴调整**自己**，也可以在一个伙伴的聊天里让它调整**别的伙伴**（同样出变更卡，卡上写明是谁）。

| 设置 | 伙伴怎么说 |
|---|---|
| 想多久再回（秒回 / 看情况 / 多想想 / 深思熟虑） | "别想那么久" |
| 回复长短（最长输出） | "回得短一点" |
| 记住多少条上下文 | "多记住一些之前聊的" |
| 温度 | "回得有创意一点" |
| 记忆：开关、和其他伙伴共用记忆 | "别记我说过的话" |

（初稿还列了"自动整理记忆""参考最近聊天""时间提醒"：这三项在轻松模式里强制开启，改了不生效，按原则不开放。）

不在本轮：系统提示词（人设）已有 `update_my_profile`；自定义请求头、请求体、正则、预设消息、工作区和电脑权限（权限类一律不交给伙伴）。

### 4. 语音

- **朗读服务**：OpenAI、Gemini、MiniMax、通义、Groq、xAI、小米 MiMo、ElevenLabs、阶跃、OpenRouter，以及系统自带。
  - Key 走安全卡片（新增 `connect_voice_service`，和第一轮同一套防护）。连上后卡片里直接**试听一句**，听到声音就说明 Key 能用。
  - 变更卡：选用哪个朗读服务、音色、语速（系统朗读还有音调）、只读引号里的内容、不读括号里的内容。
- **语音输入服务**：OpenAI、通义、火山、小米 MiMo、阶跃。Key 走安全卡片，变更卡选用哪个。没有简单的检查方法，保存后提示用户试一下语音输入。
- 音色：伙伴从目录里的可选列表挑（每个服务给常用音色和一句描述）；不在列表里的音色 id 允许填，但卡片上标"未知音色，可能读不出来"。

### 5. 备份提醒

开 / 关、间隔天数（1–90）。备份目的地（WebDAV / S3）不在本轮：它决定全部聊天记录会传到哪里，见下方"暂不开放"。

## 交互

和第一轮一样，不新增卡片样式：

- **变更卡**：每条改动一行。新加的改动类型用同一套"标签 + 短句"，例如：
  - `显示` 字号 → 大
  - `通知` 回复完成通知 → 关
  - `换声音` 朗读 → ElevenLabs · Rachel（来自 ElevenLabs）
  - `小鲸` 想多久再回 → 秒回
- **安全卡片**：语音服务的卡片和 AI 服务的一样（地址徽章、隐私说明、粘贴、申请 Key 链接）。朗读服务连上后，卡片收起成记录前多一个"试听"按钮。
- **记录与撤销**：一张变更卡里改了多类设置，也是一次撤销全部撤回。

## 工具设计

| 工具 | 变化 |
|---|---|
| `app_settings_catalog` | 新增 `display`、`notifications`、`voice`（朗读 / 语音输入服务：类型、Key 状态、是否在用、音色、可选音色）、`partners[].settings`、`backup_reminder` |
| `change_app_settings` | 新增改动类型：`set_display`、`set_theme`、`set_notifications`、`set_owner_name`、`set_partner_settings`、`select_tts_service`、`set_tts_voice`、`set_read_aloud`、`select_asr_service`、`set_backup_reminder`；`set_default_model` 新增角色 `image`（画图）；新增 `set_fast_thinking` |
| `connect_voice_service`（新） | 安全卡片：`kind` = tts / asr，`service_id` 或 `type`；朗读服务用一次合成检查 Key |

## 安全

- 语音服务的 Key 走安全卡片，加入 `SECRET_CARD_TOOLS`；存盘用 Keystore 加密（第一轮已给搜索、MCP、请求头加上，本轮补上朗读和语音输入服务的 Key）。
- 语音服务的地址：预设地址固定，伙伴不能改；通义的地址里要填工作空间 id，这类需要地址的服务交给设置页（和第一轮 Magpie 的处理一样）。
- 伙伴参数里不包含任何权限类字段（工作区、Shell、电脑控制、常驻授权）；`set_partner_settings` 遇到这些字段直接拒绝。
- 撤销快照：显示、通知、语音、备份提醒这些新加进快照的项，旧版本记下的快照里没有。快照带上**格式版本号**，跨版本比较时只比较两边都有的那几类，避免把"旧格式里没有"误当成改动，撤销时误删（第一轮修过一次同类问题）。

## 暂不开放

- **网络代理**：代理能看到所有请求，http 请求里连 Key 都能看到。
- **局域网网页服务**：会把整个 App 暴露到网络上。
- **备份目的地（WebDAV / S3）**：决定全部聊天记录传到哪里；伙伴若被网页内容诱导填了别人的地址，等于把聊天记录整包送出。以后要做，卡片必须写明"你的全部聊天记录会上传到 xxx"。
- **新增 MCP 服务器**：接上后伙伴多出一批工具，单独评估。
- 开发者模式、切换轻松 / 专业模式、更新下载地址。

## 原待定问题

1. **把几项只在专业模式生效的设置接进轻松模式？** 建议接两项："回复完自动朗读"（不接的话，配好朗读服务也只能长按消息手动朗读）和"回车发送"（实现简单）。"生成时震动""显示思考过程""聊天字体"不接。
2. **允许伙伴调整别的伙伴的参数吗？** 建议允许：只在主人的回合里，变更卡写明是哪个伙伴，可以撤销。
3. **朗读服务连上后自动试听一句？** 建议试听：比"已连接"更直观，也顺便检查音色能用。会产生一次很小的合成费用。

## 分阶段

1. 显示、通知、称呼、主题，加上默认模型补全（只扩展现有工具）。
2. 伙伴参数（含调整别的伙伴）。
3. 语音：`connect_voice_service`、试听、选服务和音色、朗读规则；语音服务 Key 加密存储。
4. 备份提醒，以及快照格式版本号。
5. 若第 1 个问题同意：自动朗读、回车发送接进轻松模式。

## 验收

- 单元测试：每种新改动的校验和拒绝（权限字段、未知主题、音色越界）；快照跨格式撤销不误删；语音 Key 不出现在目录、结果、快照、通知里；加密覆盖语音服务。
- 模拟器（脚本化假模型）：字号、主题、通知开关改完立即可见并可撤销；调整另一个伙伴的参数；朗读服务安全卡片（用假服务验证试听）；在聊天框里发语音服务的 Key 被转进卡片。

- 目录新增 `display`、`theme`（当前、可选、深浅色）、`notifications`、`owner_name`、`fast_thinking`、`default_models.image`。
- 撤销：快照新增显示、通知、称呼、主题、快速模型思考档位、深浅色。深浅色在偏好里：工具先记修订再写偏好；外观页的手动切换通过偏好监听记一版。旧快照里没有这些项时一律不动。

## 第 2 阶段实现记录（2026-11-11）

- `change_app_settings` 新增 `set_partner_settings`：`partner_id` 加任意几项 `thinking`（四档，伙伴的模型不会思考时拒绝）、`reply_limit`（1024–200000 tokens 或 `none`）、`context_messages`（20–10000 或 `all`，和专业模式下限一致）、`temperature`（0–2 或 `default`）、`memory`、`shared_memory`。**只认这几个字段**，其他字段（权限、人设、工具、请求头等）整条拒绝，并在错误里说明权限只能主人改。
- 目录 `partners[]` 新增 `settings`，以及 `is_you`（标出当前回合的伙伴，伙伴才分得清"调自己"和"调别人"）；没名字的默认伙伴在目录和结果里叫 "Default assistant"。
- `reply_limit` 是硬上限，会把回复截断：目录说明里提醒伙伴"想回短一点"应该改自己的说话方式，而不是调这个。
- 撤销：伙伴参数走已有的伙伴修订（`AssistantRevisionRecorder`），和 AI 服务、显示的修订挂在同一个工具调用下，一次撤销全部撤回；撤销时权限字段保持现状（`keepingPermissionsOf`）。
- 变更卡：标签"伙伴"，下方写是哪个伙伴；设定历史页对模型、想多久再回、回复长度 / 参考条数 / 温度各出一行，不再归进"其他设定"。
- 验证：`PartnerSettingsChangeTest`（4 项：调自己和别的伙伴、权限和越界值拒绝、目录、用真实工具一次改两个伙伴 + 字号 → 撤销 → 重做）。模拟器：在默认助手的聊天里同时调自己和 Ann，卡片正确列出；允许后目录读回新值；撤销后两个伙伴和字号都回到原样；要改 `computer_use` 直接失败、不出卡片。

## 第 3 阶段实现记录（2026-11-11）

- `connect_voice_service`（安全卡片）：`kind` = `tts` / `asr`，`service_id` 或 `type`。
  - 可走卡片的朗读服务：OpenAI、Gemini、MiniMax、Groq、xAI、小米 MiMo、ElevenLabs、阶跃、OpenRouter；语音输入：OpenAI、通义（DashScope）、火山、小米 MiMo、阶跃。
  - 只认地址仍是官方固定地址的条目；通义朗读（地址里有工作空间 id）、Fish Audio（要先在自己的声音库里选声音）、改过地址的条目和系统朗读都交给设置页。
  - 朗读服务的 Key 用"读一句示例"检查：读出来才保存，然后直接放给主人听；Key 不对、连不上、服务报错和其他卡片一样提示。记录里有"试听"按钮，用已保存的服务再读一遍（Key 不经过卡片）。
  - 语音输入没法不录音就检查，按给的保存，记录写"Key 已保存，用语音输入试一下"。
  - 连上不等于选用；选用走变更卡。
- `change_app_settings` 新增：`select_tts_service`、`set_tts_voice`（音色；系统朗读可调音调）、`set_read_aloud`（语速 0.5–2、只读引号里的、不读括号里的）、`select_asr_service`。音色不在列表里也允许，卡片标"可能读不出来"。
- 目录新增 `voice`：朗读 / 语音输入服务（类型、地址、Key 状态、是否在用、能否走卡片、音色和可选音色），以及可新连的类型。

- 安全：朗读和语音输入的 Key 存盘加密；目录、结果、修订快照里都没有 Key。撤销恢复声音设置时保留现在的 Key，地址变了的条目不带回 Key。

## 第 4 阶段：不做（2026-11-11）

- **备份提醒不开放给伙伴**：轻松模式里"提醒我备份"的开关实际不起作用。提醒卡片只在专业模式的侧边栏出现；轻松模式只用"间隔天数"给"上次备份"标颜色，开关本身什么都不触发。按"只开放在轻松模式里真正生效的设置"不交给伙伴。这是轻松模式本身的缺口，另行处理。
- **快照格式版本号**：不需要了。第 1 阶段改成"旧格式的上一版先补记一版完整状态"，比版本号更彻底，第 3 阶段加声音设置时也没再出问题。

## 第 5 阶段实现记录（2026-11-11）

- **回复完自动朗读接进轻松模式**：聊天页开着时，伙伴回完的消息自动朗读（遵守"只读引号里的""不读括号里的"）；其他聊天的回复不读，App 在后台也不读。
- **新页面"我 → 朗读"**：自动朗读和两条朗读规则的开关，朗读的声音、语音输入跳到完整的语音设置页。伙伴打开了自动朗读，主人在这里就能关。
- 伙伴：`set_read_aloud` 新增 `auto_read`；目录 `voice.tts.auto_read`；撤销快照新增 `display:tts_auto`。
- **回车发送不接**：轻松模式的输入框本来就是输入法上的"发送"键直接发送。专业模式的"回车发送"默认关，接进来反而会让所有人的回车变成换行。
- 验证：`VoiceSettingsTest` 新增自动朗读的改动和撤销。模拟器："我"里出现"朗读 · 手机自带"，页面三个开关和两行服务正常；打开自动朗读后发消息，伙伴回完时系统朗读引擎合成并播放了回复。

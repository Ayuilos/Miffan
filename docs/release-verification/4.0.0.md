## Checks

- `./gradlew test lint assembleDebug` on the merged branch before the version bump: passed.
- PR #38 CI: the first run failed once in `workspace` `PersistentRemoteShellTest.completedTerminalsCannotSendDelayedInputToTheNextCommand` (5 s timeout); the sync does not touch the `workspace` module, 20 consecutive local runs passed, and the CI rerun passed. Treated as a pre-existing timing flake to investigate separately.
- In-place upgrade on an API 35 emulator from the official `3.4.4` APK: three conversations with a regenerated branch, a pin, a favorite, two assistants, an assistant-written memory and changed preferences were created through the UI, then `adb install -r` the candidate. Same package and signer, higher version code. The one-time mode choice appeared; professional mode kept all state and continued chatting; easy chat showed the assistants as partners with their old conversations, replied, and opened settings history and memory; switching back lost nothing. No Room migration error.
- Fresh install of the candidate starts in easy chat onboarding.
- One ANR (input dispatch timeout, main thread recomposing) occurred on a force-stop relaunch during the upgrade run, with host load average 10.8 from two emulators. It did not reproduce in 20 further cold starts of the candidate over a larger 4.0 data set (10 in easy chat, 10 in professional mode): apart from the first launch after installation (5–13 s while the new APK is compiled), launches took 0.2–2.6 s with no ANR. The owner had already exercised the main flows on a physical device. Publication was approved with this finding recorded.
- Website: 96 tests passed; production build and all 19 help-topic hashes validated; live manifest and topic hashes verified after deployment.
